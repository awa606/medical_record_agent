# 当前阶段

**EVT / Alpha。** Project OS 项目首页记录的路线为 `POC → Alpha → Alpha+ → Beta → EVT Exit / Ready for DVT`。当前计划快照为 2026-09-10；该快照中的 15 个 Alpha 叶子任务均为 `backlog`，不能宣称 Alpha Gate 已通过。

## 已完成

- POC 报告和演示资料记录了三种输入进入同一病历草稿、医生审核和导出闭环的课程验证。
- 当前代码基线 `v1.4.0` 已记录服务端角色质量门禁：低置信、未映射说话人或混合语句不能进入正式病历生成。
- POC、Alpha WBS、EVT 路线、产品生命周期图、计划工作簿和可编辑 Draw.io 源文件已经归档。

以上内容是已有材料或代码版本的事实，不构成真实临床、离线部署或 Alpha Exit 验收通过。

## 进行中

## 技术风险

- 本地模型在目标环境的离线加载、延迟和内存占用尚需实际验证。
- 医患角色错误可能导致病历内容归属错误；服务端门禁已存在，但真实录音下的质量和人工确认负担未完成 Alpha 验收。
- 审核、Revision、导出和前后端状态必须在真实 E2E 中复测，不能以历史演示或代码存在替代。
- 当前 POC 使用普通电脑、浏览器和麦克风；边缘设备、专用终端、连续录音、噪声环境和医院接口仍是 EVT 以后待验证范围。
