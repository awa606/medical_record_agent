## 当前方案

Jetson独立运行ASR、真实LLM与后端。现有电脑只负责网页操作和USB麦克风采音，通过局域网连接Jetson。8GB是CPU与GPU共享内存；CPU、GPU、载板、电源和原装散热按一套开发套件计价。

套件官方参考价2070元，SSD、外壳、麦克风、网线与安装U盘五项缺价，不能确认完整方案低于3000元。历史2699元办公主机方案和开发机CPU实验不能作为Jetson验收。
