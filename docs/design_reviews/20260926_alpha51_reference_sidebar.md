## 展示规则

- 诊断条目仅显示已有名称。治疗优先使用已有实时`care_plan.title`；非结构化长文只显示“查看处理建议”，不做模型概括。
- 原文、指南、风险和缺失项保留于详情。没有单项关联的内容在折叠的“病例级参考（未关联单项）”中呈现，不冒充某诊断或治疗依据。
- 未确认角色、Revision冲突和未批准导出的原阻断继续生效。查参考不更改编辑缓冲、批准或导出资格。
- 详情使用Esc、关闭按钮、Tab约束与返回焦点；录音中的参考详情可关闭而不终止采音。异步重绘入口后仍恢复到对应条目。
- 标题变大后，将左栏“显示设置”移到输入工具条，避免标题与按钮争宽；保留原事件ID。
- CSS在既有工作区作用域修改，新增参考列表不继承旧等高/小字号卡片规则；不改登录或管理后台布局。

## 固定五问与结论

1. 名称导航与完整详情分离，使医生先扫视、按需核对；保留已有三栏操作习惯。
2. 右栏内展开会重新堆积长文；重建页面或换框架不解决信息层级问题，沿用现有抽屉。
3. 最可能失败的是CSS覆盖、窄列标题换行和抽屉焦点；均纳入实际页面回归。
4. 最小验证使用既有本地API测试服务器与合成长病例，无需运行模型或重新录音。
5. 以字段/证据不丢失的交互断言、前后截图、真实缩放与用户版式认可证明完成，不能仅凭测试数宣称视觉通过。

ASSUMPTION A01：本轮只改变呈现；历史三路径与r6恢复属于旧SHA证据，不能自动升级为本轮稳定版本。A02：详情未携带的临床信息保持缺失，不从其他字段补造。
