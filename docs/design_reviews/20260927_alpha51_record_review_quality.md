# 5.1 病历核对与质量定位设计

日期：2026-09-27。Research：ADAPT 既有医生工作台；Design：PASS（仅本节交互）。训练数据与 QLoRA：NEEDS MORE EVIDENCE。

## 设计边界

| 评审项 | 决策与验证 |
| --- | --- |
| 1 目标 | 医生能定位问题字段、修改、确认保存版本、处理并发冲突、审核及导出 |

| 5 约束 | 不改转写布局、公共 API、数据库、模型、阈值；不把规则回归算作模型质量 |

| 7 模块划分 | 字段定位、待处理审核、冲突恢复各自独立；检索及转写组件保持原边界 |

| 9 状态 | 编辑中的值不因切换字段丢失；读取最新版本失败时恢复本地编辑状态 |

## 五问

1. **为什么这样拆？** 将医生操作错误、模型错误和校验错误分开，避免用UI完成掩盖提取漏项。
2. **还有什么替代方案？** 保持整页入口或重写状态管理；前者不解决定位和失败丢失，后者不适合展示冲刺。
3. **最可能失败在哪里？** 保存成功但后续读取失败、并发版本刷新中途失败、切换任务误用本地恢复值。
4. **最低成本怎样验证？** 在真实HTTP测试服务中制造409和读取失败；对相同音频分别使用人工真值与ASR输出调用同一模型。
5. **怎样证明完成？** 有可操作候选、上述失败回归、匿名证据和对应版本；5.1仍须最终真实三路径和离线恢复。

ASSUMPTION A01：当前8795用于候选验证，旧2626不是交付前提。A02：没有医学复核人员，数据仅支持工程验证。A03：模型配对实验失败时保存失败，不能替换生产权重或降低门禁。

界面基线不是稳定发布。当前训练路线未通过数据许可、标注和资源最小实验，因此本设计不授权扩大训练。
