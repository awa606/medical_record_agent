## 固定五问

1. 按患者事实、外部依据、待核对项拆分，符合核对顺序且避免混淆来源。
2. 连续长页为备选；用户选择摘要＋标签页，不再重开版式取舍。
3. 最大失败点为当前部署数据未挂接；先核查环境，隔离副本通过不冒充2626在线通过。
4. 最小验证只需一病例、三标签及一条现有知识查询，不启动模型或重建检索引擎。
5. 以实际DOM浏览器测试、截图、来源哈希、API结果及用户视觉认可证明；历史测试不代替新版本。
