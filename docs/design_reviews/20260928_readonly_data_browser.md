# 独立数据浏览器 Engineering Design Review

输入：[Research PASS / ADAPT](../research/20260928_readonly_data_browser.md)。Design Review Gate：**PASS**，表示实现边界与验证方法明确，不等于产品验收。

| 评审项 | 冻结决策 |
| --- | --- |
| 1 Goal | 为29日展示提供可核对的表、字段、版本与关联；转写页面不变 |
| 2 Deliverables | 快照导出器、受限Datasette、启动/刷新/停止脚本、测试和操作说明 |
| 3 Input/Output | 输入指定SQLite及人工审阅的匿名患者ID清单；输出独立只读SQLite、采样清单和本机页面 |
| 4 Constraints | 最多1小时包装；生产API/Schema不改；不上传库、原音频、模型或凭据 |
| 5 Largest uncertainty | 投影遗漏关联或输出多余敏感内容；通过白名单和外键校验阻断 |
| 6 PBS | 数据快照包、独立浏览器启动包、工程验证证据 |
| 7 Architecture | 8795运行库只读连接→内存一致备份→白名单投影→immutable Datasette；不挂载运行库 |
| 8 Modules | 导出器拥有投影和清单；Datasette拥有只读交互；启动器拥有自己的进程与本地登录信息 |
| 9 Interfaces | CLI输入源库/输出目录/允许ID清单；错误非零退出、保留旧快照；应用公共API无变化 |
| 10 WBS | 5.1辅助展示与缺陷收敛；不新增叶子；额外投入计R11 |
| 11 Dependencies | 快照导出→内容审查→浏览器验收→包装；不依赖Jetson或新模型候选 |
| 12 Critical path | 采用2026-09-28T00:05:57+08:00共享PM快照；不另算CPM，5.1发布证据仍是下一正式门禁 |
| 13 Risks | 敏感数据：ID/列/JSON白名单；依赖：独立锁定venv；快照过时：时间标识；工期：超时停止扩展；回退：只停工具 |
| 14 Minimal validation | 两表Spike已通过；真实投影校验行数/外键/源库不变，再查鉴权、SQL、下载、写入 |
| 15 Acceptance | 业务与知识各一条可点击关联；只读与权限通过；重启、刷新不丢旧快照；未满足即VERIFY |

固定五问：如此拆分是为避免浏览器接触运行库；替代是自建实时后台（本次不选）；最可能失败在数据投影；最低成本验证为匿名两表Spike及真实白名单副本；完成证明是实际页面、HTTP拒绝、行数与SHA证据，而不是截图数量。

ASSUMPTION A01：已有显式合成演示病例允许本机查看，不因此扩大真实患者数据授权。A02：独立浏览器使用本地root登录，不能代替应用内RBAC。A03：仅固定白名单内容可刷新；未知表/字段不自动加入。

进程只绑定127.0.0.1，8796优先、8797备用。登录令牌和PID信息仅存忽略目录；停止时验证PID与命令行一致。禁止任意SQL、下载整库和写操作。刷新产生新目录，成功后再切换工具，不修改旧快照。
