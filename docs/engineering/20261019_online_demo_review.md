# 2026-10-19 在线审核展示候选：增量研究与设计

## 决策与边界

目标是让现有登记、转写、草稿、原文与指南、修改、审核、导出、历史和数据查看能连续演示。用户已授权 DeepSeek API，当前预算20元；密钥在本机私密配置填写，不提交Git。保持医院临床验证与本地Alpha出口独立。

研究输入为 `scripts/experiments/deepseek_spike_research_20261019.json`。17项本地接口测试和3次真实API请求证明既有七字段契约可以适配官方服务；3例仅I01达到完整覆盖预期，B01漏否认胸痛，P01有遗漏及待定位规则拒绝。

**Research PASS仅适用于HTTP接入、受控费用和可追踪审核候选的技术选择；模型完整性、实时角色及稳定发布仍为NEEDS MORE EVIDENCE。** 采用ADAPT现有Provider、Generator和启动器。直接改环境变量会被离线网络及固定启动器拒绝；新增框架不能解决当前事实遗漏，故不采用。失败保留原本地配置与数据库，不静默切模型。

## 设计输入与输出

- 输入：合成／已授权去标识问诊文本；音频仍由本地FunASR处理；输出保持现有MedicalRecordFields、task结果和Revision兼容。
- 在线候选固定 `deepseek-flash`，官方HTTPS Chat Completions，非思考、JSON模式、temperature=0、输出4096 tokens、零自动重试。该配置来自已运行Spike，不新增提示词实验。
- 私密配置只本机读取；请求显式脱敏。响应记录实际model、请求ID、finish_reason、usage、耗时；原始内容只在授权诊断目录。HTTP错误显示安全中文原因／错误码，不回显服务商错误正文或凭据。
- 调用前保守预留费用，项目共享账本上限20元；失败／超时保留预留，超限拒绝。价格按本轮核验峰值计算，仅管理本项目费用，不能约束账户其它客户端消费。

## 模块职责与接口

| 模块 | 所有数据与变化 | 验证 |
|---|---|---|
| DeepSeek适配 | HTTP请求、响应、预算；复用既有online入口，不新增业务API | JSON、截断、空响应、401/429/5xx、超时、零重试、日志脱敏 |
| Generator与审核 | 原引用、字段隔离、人工来源、Revision仍由现有代码负责 | 正确字段可用；冲突未处理不得批准导出 |
| 就绪检查 | 在线模式用有认证的模型列表探测连通性，缓存短期结果，不做周期收费生成 | 配置不等于可用；断网/鉴权/模型不存在拒绝；历史读取保留 |
| 启动器 | profile缺省local_qwen；online_deepseek仅app/gateway，保留互斥、空闲、镜像及资源指纹 | 旧配置兼容；线上不要求或启动Ollama；不能误开旧环境 |
| 部署 | 保留旧离线Compose；独立在线profile启用应用出网，API适配器只接受官方HTTPS端点且拒绝重定向；ASR缓存离线 | 不宣称容器所有出网都被网络级白名单限制；密钥不写镜像 |

公共HTTP接口、数据库表、七字段和安全阈值不变。追加运行配置与现有trace元数据，不改已保存历史事实。模型列表成功只表示可连接，不代表病历质量通过。

## 工作拆解、风险与验收

交付依赖：技术Spike（已完成）→在线适配及启动器→隔离副本→API/页面闭环→备份切换8798。导出和历史状态为独立确定性修复，可并行。实时ASR单独使用资源预检和原授权音频验证；没有可靠身份的稳定句不生成患者事实。正式CPM本轮无新实时快照，不另算或更改排期；仍16项99h，5.1 VERIFY。

最大未知是内容完整性及实时角色，不因接口成功宣布解决。B01遗漏保留为模型失败；P01先做完整链正反例定位，规则修复独立记录。网络失败保留输入，不Mock回退；并发、旧Revision、未批准导出继续拒绝。资源不足不关闭其它程序，不并行加载本地大模型。

验收采用同一匿名病例经可见按钮完成文本／授权音频输入、核对、保存、审核、导出、重开；导出实际文件检查；知识来源与数据关联可查看。定向测试后全量回归。每日演示记录版本、实际Provider、输入来源、首次结果与人工修改；物理麦克风和实际缩放缺少时继续标未验，不以回放冒充。

ASSUMPTION A01：今日展示使用合成／已授权去标识材料；API生成必须联网。ASSUMPTION A02：用户尚未回答录音当中角色细化问题，先交付真实增量文字与可核验的结束后角色处理；实时身份仍独立研究，不猜测。

为什么这样拆：故障分别属于接入、语义、界面及部署，独立验证避免互相掩盖。替代方案是继续本地模型或全新框架；前者保留回退，后者超出今日最小改动。最可能失败在事实遗漏和角色，而非HTTP。最小验证复用已有原始输出与三例Spike；完成证明是实际界面闭环、文件内容和重启持久化，不是测试数量。

**DESIGN REVIEW GATE：PASS用于实施受控在线审核候选；部署放行须运行验证；模型质量与稳定产品Gate未通过。** 不替代5.1真实本地路径、5.2断网或M4要求。先保留数据和旧配置，再部署；任何失败恢复原本地候选，失败证据不删除。
