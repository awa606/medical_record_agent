# 本地提取故障分层与最小验证（2026-10-24）

## 结论

现有失败不能统一归因为“小模型能力不足”或“提示词不好”。本轮只使用已有原件，定位到四类不同环节：**事实目录没有允许字段、模型没有选择合法事实、研究契约的独立子句缺少明确患者主体、完整字段输出本身错引或错放主体**。这些问题需要分别验证，不能用强制非空、自动补写或医生修订把首次失败改记为通过。

功能检查子智能体完成独立离线追踪：完整字段契约5份、事实选择研究契约6份，共11份代表响应；另只读核对最近字段释义实验的3份原响应。没有新增模型或ASR调用，没有修改生产、测试、业务数据库或历史报告。读取、映射及RecordedProvider回放均在独立本地目录，网络连接被显式拒绝。

8798仍采用前端`cd56f59d`、后端`4b041cf4`及在线DeepSeek。这里的本地Qwen研究结果不代表线上当前模型，也不改变展示版的运行配置。

- 完整字段原件：9月28日`baseline4b`中的`realtek13`、`case11`、`question`、`family`、`treatment`各第1次响应，输入哈希与原输入清单一致。
- 事实选择原件：10月16日`pressure`上述5例及`missing`各第1次响应。使用当时保存的事实目录及原始选择，未用今日目录替换历史输入；当前目录仅作允许字段比较。
- 最近用药漏提：10月24日字段释义候选的3份响应，只读检查原始选择、结束原因及保存的映射结果，不重复运行模型。
- 所有原件读取前后SHA256一致。病例原文、模型原响应、逐阶段完整数据和本地身份存储不加入Git。

这是小范围故障定位，不重新计算历史整套通过率，也不是临床准确率评测。原始字段、映射结果、规则状态和人工修订分别评价；本轮人工修订为0。

## 三类错误的逐阶段定位

| 输入／契约 | 目录与原始输出 | 映射与校验结果 | 定位与下一项最小处理 |
| --- | --- | --- | --- |
| `realtek13`／完整字段 | 生产契约不使用事实ID目录；首次有4个字段，主诉引文不在原文中且编号与文字不匹配 | 当前完整Generator仍隔离主诉冲突；其他字段继续保留。没有补造原引文 | 引用生成错误。修引用机制时用此原件及合法引用控制例回放，不重跑历史79次 |
| `family`／完整字段 | 模型将家属自身过敏事实放入患者主诉及过敏史，引用文字本身能匹配 | 来源校验后在主体检查阶段两字段冲突，全矛盾以`LLM_OUTPUT_CONTRADICTION`拒绝 | 首次主体选择错误；规则拒绝正确。不能把“引文存在”当作“属于患者” |
| `treatment`／完整字段 | 已用药与反应只进入现病史，既往处理缺失 | 当前链保留现病史，不自动把它复制到既往处理 | 模型字段覆盖遗漏；正常返回部分稿不等于预锁定字段完整 |
| `treatment`／事实选择 | 原目录分别允许现病史与既往处理选择1个事实；原模型却返回七空数组 | 映射原样为空，完整链以`LLM_NO_SUPPORTED_FACTS`拒绝 | 模型选择为空，不是映射器丢字段。unknown标签与中文释义两轮均失败，不再重复它们 |
| `missing`／事实选择 | 原目录中所有字段允许数量均为0，模型只能选择空 | 映射为空，完整链明确无可用事实 | 开放表达的目录覆盖缺口；不能拿此例证明模型忽略了合法候选 |
| `case11`／事实选择 | 原目录与原选择均包含伴随症状事实；模型选择没有被映射丢弃 | 映射正文及引文与原件一致，但其中独立家属子句未显式保留患者主体；当前grounding将伴随症状标为`conflicting` | 研究契约的子句主体表示与当前保护规则不兼容。需要单独验证主体锚，不通过删除家属限制解除冲突 |

事实选择`case11`在较早代码下的历史通过结果仍保留；本轮当前链出现冲突是新回放结果，不能覆盖旧报告，也不能继续把旧15/21成绩当作当前链成绩。该研究契约尚未进入生产。

## 最小后续矩阵与停止条件

本地研究下一项只诊断固定用药输入的**可选ID生成兼容性**，与现有完整字段契约明确分开。若强制某字段非空，只能说明解码是否能输出该ID，不能记为理解正确或部署方案。无需重复失败的标签和字段释义候选。

| 变化范围 | 最小受影响验证 | 停止条件 |
| --- | --- | --- |
| ID输出约束诊断 | 固定原目录、输入、模型摘要、温度及参数，保留首次原始选择；比较原始、映射和最终阶段 | 传输／资源异常停止；强制非空的成功不晋级，也不自动扩到开发或冻结集 |
| 主体锚方案 | 只处理`case11`的家属代述正例，并配家属自身病史、医生未回答问题反例 | 正例仍被拒或反例进入患者字段即停止；不删全部家属规则 |
| 完整字段引用／覆盖 | `realtek13`错引、`treatment`漏项的原响应回放与各一个合法控制例 | 引用被猜补、正确字段退化或异常被算成功即停止 |
| 当前展示候选 | 当前组合版本的一次既有授权音频可见按钮新流程，分别保存首次内容、人工修订与导出结果 | 发生首处运行／角色／保存／Revision阻断时保留输入，定位该层，不循环调用 |

先前31项、E-8来源显示、E-23历史播放及切换不受本次只读研究影响，直接复用。历史E-23生成来自55c，不能把本轮播放记录当作当前版新音频生成。物理录音、实际缩放、独立恢复及5.3连续五次继续分别保留门禁。
