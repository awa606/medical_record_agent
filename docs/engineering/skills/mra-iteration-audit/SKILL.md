# MediListen 迭代收尾复核

本Skill落实用户要求：每次实质交付后检查产品是否更可用、功能是否衔接、演示是否容易完成。它是助手执行指南，不是已接入程序的自动拦截器，不修改WBS、验收阈值或发布权限。只读咨询和无事实变化的回合不制造审计文件。

用户已澄清原要求是sd.webui的自制子智能体。本Skill只负责安排复核，不能替代实际委派。读取项目内 `docs/engineering/agents/mra-review-roles.md`，按其中职责使用当前子智能体工具；每轮至少一名未参与对应实现者，模型／规则与流程分别交框架、功能检查者。涉及界面变更再做审美实际检查，无变更可复用有效基线。报告代理真实执行范围，不把Skill格式校验称为代理审查，不声称运行了sd.webui原本的本地模型。工具不可用时明确未执行。

## 先确定这次真正改变了什么

- 以当前Git工作树、运行入口及既有任务为准，分别记开发SHA、实际镜像／运行SHA、模型及契约、数据环境。文档提交不能冒充运行版。
- 列出变化影响的输入、输出及下游操作，先读相关失败原件与最新修复记录。尚未定位的原因写为假设。
- 给本次交付一个可观察结果，例如“医生修改后能保存、查看原版并继续审核”；不要用新增文件或测试数量充当完成条件。

## 复用证据，只补真正缺少的检查

已通过且未受影响的证据记录为`REUSED`，引用原时间、环境、输入、源码／资源SHA、证据路径及校验值，说明为何仍适用；不改写旧结果时间，不强制重跑。仅核对必要指纹与依赖，避免为复用扫描整库。

有代码、配置、模型、资料版本变化，或发现未覆盖操作、失败、新环境差异时，补受影响测试。跨版本的单项成功不能拼成同版本全流程通过。哈希一致只证明内容一致，不能证明服务、外部网络或实际设备仍可用。

## 分层判断，不能用一项成功抵消另一项失败

| 层级 | 复核问题 |
| --- | --- |
| 本地模型首次输出 | 当前输入上的字段归属、事实覆盖、引用、否定、主体、数值是否满足既有预期？区分本地／在线模型；未实际调用只记回放，不把在线成功写成本地质量。 |
| 规则与人工处理 | 哪些错误被隔离，哪些仍漏拦？人工修订、接受缺失和批准分别记录；导出成功不表示首次内容完整。规则修复不能算模型提升。 |
| 功能联通 | 受影响路径能否从登记、输入到核对、保存、历史版本、审核、导出与重开？接口、合成DOM、可见按钮、物理设备证据分别标识。 |
| 演示与可用性 | 当前页面是否清楚说明下一步？记录具体多余操作、帮助内容、重复确认、返回丢上下文或状态误导。正常完成也记录，不强行编造痛点；没有真人试用不填完成率、满意度和时长。 |
| 权限与数据 | 本轮是否影响角色门禁、患者关系、未保存内容、旧Revision、批准或导出？知识停用、引用来源、只读快照白名单与采样时间是否仍清楚？ |
| 交付与恢复 | 入口、手册、镜像和恢复材料是否对应？原目录重启、新目录恢复、断网资源恢复、断网生成分别判断；未测设备与5.3连续流程不从其他成绩推定。 |

已有模型门禁和固定数据集继续使用。不为凑通过改标签、挑成功输出、隐藏首次失败、自动重试或降低阈值。已拒绝的路线只有出现针对原失败的新证据才重开；研究预算与授权沿用项目记录，不从插画项目照搬采样次数。

## 将界面经验转成具体检查

需要审查界面时可调用已安装的`aesthetics-system`，仅取本任务相关知识。先固定病例、内容量、状态与设备，再判断阅读顺序、标题正文层级、状态反馈、取消和返回；不要扩成全站改版。实际缩放、真实键盘与合成小视口分别记录。

该方法借鉴sd.webui的有条件知识应用与PixivDesk版本化验收：技术通过、视觉复核、用户认可分别写。引用知识条目时保留ID、查询哈希与读取范围；只读知识卡不能称已看完原视频。审美原则不能证明医学事实正确。

## 收尾输出

在本轮原有证据报告追加简短矩阵：`功能／期望／实际／PASS、FAIL、NOT_TESTED或REUSED／版本与证据／下一最小动作`。存在阻塞可写`BLOCKED`并列前提。复用项目原问题ID；新确认缺陷登记稳定ID与首次证据，不为每轮同一问题重新编号。

失败固定包含：模块、输入ID、预期与实际、影响、原始证据、下一最小验证。保留唯一失败原件；按现有脱敏和归档规则处理，不上传原病例、录音、凭据或私人反馈。

结论分别给出“本轮改动可交付程度”“完整试用版剩余门禁”“医院部署独立缺口”。医院部分只核对现有Enterprise路线及本轮受影响项，例如患者授权、审计、恢复、接口、临床合作与独立评价；不另起正式WBS、不自行改期，也不凭工程检查宣称医院级或临床安全通过。

按现有PM与`mra-engineering-report`规则同步和汇报，最终只指出一个最优先的下一动作。没有新事实不刷新镜像或时间戳。
