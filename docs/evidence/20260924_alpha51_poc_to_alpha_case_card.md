## 输入与原始证据边界

本轮三条 Alpha 路径均为匿名发热场景：文本使用明确标注医生／患者的合成对话；上传使用一段授权课程双人问诊录音（60.000 秒，SHA256 `e0d16a3192b99ee99c74fc730facd22338cd4da2a3bb28da980d6d99375f74a4`）；浏览器录音由用户在 Edge 使用 Realtek 物理麦克风朗读匿名测试句（11.008 秒，SHA256 `49c1f264172f24032e21304e9fb46a35885eaa52e2bd5814d946c869612d5054`）。三者症状主题一致，但并非同一段录音或同一份病史，不能互作独立质量样本。

原始音频、SQLite、完整模型日志和 DOCX 均保留在被 Git 忽略的 `.artifacts/alpha51-real-20260924-verify-5/`。Git 只保存匿名指标、哈希及截图。三路径原始指标可用 `scripts/alpha51_summarize_real_smoke.py` 从该本地目录重算。

冻结 POC 的历史基线为 [前端验收记录](../final_report/images/v1_0_frontend_acceptance/frontend_acceptance_evidence.json) 和 [首页截图](../final_report/images/v1_0_frontend_acceptance/01_doctor_workbench_home.png)。它已经有三栏、文本／音频上传、转写显示、证据面板及角色校正；这些不是 Alpha 新增功能。POC Runbook 允许真实 ASR 慢时切回 Mock，本轮 `local-real` 路线没有此回退。旧 2666 容器与证据维持停止和原样。

## 已复核结果与失败记录

- [三路径机器摘要](20260924_alpha51_real_three_path_smoke.json)：**3/3 工程 Smoke 通过**，每条都达到“生成→修改→审核→导出”，并记录独立任务、Revision、音频与导出文件 SHA。文档结果可从本地原件重算；它不证明医学质量、多人泛化或企业级临床安全。
- 文本初次生成时，Qwen 给主诉附了不在原文中的引用，字段为 `conflicting`，直接审核被阻断。医生改写后若页面继续携带旧引用，仍被阻断。现已在编辑器中撤下被改字段的旧 AI 引用，保留原文对照、标记 `partial`，再次逐项审核后才能导出。这两次失败结果未删除。
- 文本导出保留“没有花生过敏、没有药物过敏史”；麦克风导出保留“没有药物过敏史”。上传音频未提供这两项事实，不能把空值解读为阴性。三个导出均不含旧 Mock 的“蛇咬”内容。
- 物理麦克风输入由一名测试者朗读合成病例句；角色确认是人工指定的模拟患者角色。这证明浏览器采音与角色恢复技术链，不等于真实双人门诊的角色准确率。
- 可看见的 UI 变化包括：顶部患者及五步边界更清楚、三栏字号和间距固定、点击“开始录音”直接进入问诊、停止后再试听／提交，以及文本／上传入口与录音状态互不叠加。[认可的待采集](images/alpha51_v34_review/empty-1440.png)、[录音](images/alpha51_v34_review/recording-1440.png)、[病历](images/alpha51_v34_review/draft-1440.png)均为固定数据样稿，不冒充真实模型截图。
