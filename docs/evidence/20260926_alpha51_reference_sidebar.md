# WBS 5.1 参考栏与标题层级修正

右栏原先同时铺开诊断理由、治疗长文、实时参考、证据和知识卡片。现在默认仅显示诊断名称和治疗标题，点击原有侧边面板阅读完整内容。保持三栏比例及五步流程。

## 交付

- 诊断／治疗两个自然分区，间隔20px；名称16px，按钮至少44px，空态一行。
- 长文只在详情展示；治疗无结构化标题时使用固定“查看处理建议”，未生成新医学摘要。
- 详情保留原文、缺失信息、补问、检查、用药、风险和来源。无单项关联的材料归入“病例级参考（未关联单项）”。
- 左侧导航16px加粗、辅助说明13px；产品标题22px、三栏标题20px、流程与顶部操作15px。转写16px和病历17px保持不变。
- 支持Esc、焦点约束及返回入口；录音时看参考不会停止采音；未保存编辑不丢失。角色409、Revision和审核导出保护继续由原业务逻辑控制。
- 未改公共API、数据库、模型、诊断内容、阈值及WBS基线；[设计记录](../design_reviews/20260926_alpha51_reference_sidebar.md)。
