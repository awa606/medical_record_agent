| 问题层 | 改动 | 保留的保护 |
|---|---|---|
| 草稿显示 | 以七个字段隔离冲突；正常正文只显示“待核对”，拒绝的模型内容在核对详情中保存 | 自动通过仍是“待医生确认”，不等于医学正确 |
| 生成结果 | 使用可用字段计数；全空、全冲突或无法解析进入失败，不建立正常待审核版本 | 保存原始输入和失败诊断，不静默重试 |

| 帮助 | 现有手册在dialog＋iframe内打开，链接留在面板，Esc关闭并返回焦点 | 不公开日志、账号文件或整个文档目录；保留离线帮助的版本标识 |
| 异步参考 | 已关闭“查依据”后，晚到结果不再重新打开面板，不覆盖编辑或帮助 | 丢弃跨就诊的过期响应，后台知识查询不改患者事实 |
