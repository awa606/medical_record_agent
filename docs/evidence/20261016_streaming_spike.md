# 2026-10-16 实时转写隔离实验：资源保护停止

## 1．结论与边界

**本地在线模型加载成功，但在预热和音频推理前触发预先登记的子进程资源上限，实验停止。10秒／2秒两臂均未执行，不能比较延迟、积压或识别质量。**

本轮没有替换生产模型、修改服务参数、停止活动容器或写入业务库。实验结束后8798 `/health` 返回200，应用与Ollama容器均保持运行、`OOMKilled=false`。这次停止是实验保护条件触发，不是操作系统OOM，也不证明该模型无法在本机运行。

这是单次工程Spike，不是物理麦克风、浏览器SSE、双人角色准确率或正式发布验收。此前ASR输出不能充当人工转写真值。
