# 2026-10-19 实时转写分块延迟对照

## 结论

同一份已授权60秒录音，在隔离容器中按真实时间依次执行10秒、2秒分块，各一次，无自动重试。**2秒分块达到本次单样本的工程延迟目标；10秒分块未达到首字目标。正式运行配置尚未启用2秒分块。**

本轮没有浏览器、网络传输或物理麦克风输入。稳定段仍无医患角色；两臂转写文字存在差异，尚无人工真值评测，因此不能将延迟结果解释为识别质量不退化、自动角色通过或完整实时问诊验收通过。

## 实测结果

以下首字时间从每臂开始计时；P95从音频块结束时刻计至引擎返回稳定段，均不包含浏览器与SSE传输。

| 指标 | 10秒分块 | 2秒分块 |
|---|---:|---:|
| 首个返回文字 | 12.686秒 | 2.597秒 |
| 块结束至稳定文字返回P95 | 3.075秒 | 0.864秒 |
| 处理RTF | 0.290 | 0.332 |
| 顺序处理的输入块 | 6/6 | 30/30 |
| 输入块漏序、重复、乱序 | 0 | 0 |
| 本次工程延迟目标 | 首字超过4秒，未通过 | 本次样本通过 |

沿用的工程目标为：首字≤4秒、稳定返回延迟P95≤5秒、RTF<1、输入块漏序／重复／乱序为0。输入块完整不等于转写文字无遗漏或重复。

模型构造加载25.441秒，单次静音预热0.322秒，两项单独记录，不计入上述预热后的实时延迟。两臂中最大队列等待约0.0013秒，没有触发15秒积压停止线。
