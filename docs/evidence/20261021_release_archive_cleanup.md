# MediListen 历史版本归档与空间清理证据

**状态：C／D 盘精确清理完成，Obsidian完成事实已同步。** 本轮始于 2026-10-21，记录于 2026-10-22 更新。171 个附件已完整取回核验，5 个载荷及其成员还原通过；121 个精确历史副本已移除，逻辑大小 105,252,254,992 字节。清理窗口内 C 盘可用空间增加 **105,003,618,304 字节，约 97.79224 GiB**。D 盘本轮清单中的 340 个传输副本也已移除，逻辑大小 46,261,629,760 字节；三个清理窗口的可用空间增量合计 46,194,307,072 字节，约 43.022 GiB。

本报告用于历史归档和存储管理，不是新的产品发布。现有失败记录、模型质量结论及 WBS 验收状态不因归档改变。恢复操作见[历史产物归档与精确恢复](../runbooks/20261021_release_archive_restore.md)。

## 1．为什么会占用约 161.7 GiB

此前可读取文件盘点约为 161.7 GiB，主要由完整镜像、模型缓存及多次恢复副本组成。这个数字是文件逻辑大小的汇总，不等于本轮可释放空间，也不是本次重新扫描整个磁盘的结果。

| 原盘点类别 | 约计逻辑大小 | 本轮处理方式 |
|---|---:|---|
| 历史完整基线包 | 63.2 GiB | 按精确文件审查归档，不整删目录 |
| 五套恢复验证副本 | 47.7 GiB | 先核对实际运行引用；保留仍在用的模型 |
| 当前开发目录其他内容 | 9.3 GiB | 保留当前开发、教师材料及排障证据 |
| 原主仓库、模型、数据及虚拟环境 | 23.4 GiB | 共享 Git 与业务资料受保护；未证明可重建的缓存暂缓 |
| 其他工程及课程材料 | 18.1 GiB | 不扩大本轮清理范围 |

以上类别为近似值，不能相加后作为精确删除目标。直接原因是此前完成了本地打包及恢复，却没有完成“远端完整取回核验 → 精确清理副本”的最后一步。此外，部分历史恢复目录后来成为当前模型挂载来源，不能按日期或名称淘汰。

本轮细查覆盖 **12 个历史包／恢复目录**。初始候选中有一个镜像含未确认可公开再分发的项目录音，已排除；最终公开白名单为 **477 个文件、38 份不同的 SHA256 内容**。477 个路径的逻辑大小为 **116,540,083,448 字节**，按不同内容只计一次为 **11,014,170,081 字节**。相同内容被多个版本重复保存，是此次可减少占用的主要来源。
