# 转写时间与来源显示修复（2026-10-24）

## 结论与范围

用户截图中的E-8保存的是文本输入，未关联录音。旧界面逐行展示`--:--`，未说明为何没有时间；另在8798的真实音频历史E-23复现播放器横向裁切。修复限于三份静态资源及回归测试，后端、模型、原文、数据库及批准记录不变。

- 文本输入（含历史`text-import`）明确显示“文本输入 · 未关联录音／本病例没有音频时间”，正文及详情不再显示伪时间。
- 音频来源以持久化`asr_source`等实际关联识别，不能只看任务`input_type`：音频生成的病历任务也可能为`text`。
- 保留真实时间、总时长和定位；音频缺失时间明确显示“时间未记录”。
- “跟随播放”仅过滤音频的已知时间段，切回文本不再隐藏原文；未知时间音频原文仍可查看。
- 播放器适配窄左栏，播放、完整时间、进度、音量和倍速不再横向裁切。正文仍16px，病历17px，章节标题20px。
