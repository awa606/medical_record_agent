## 固定排版规则

| 项目 | 规则 |
|---|---|
| 色彩 | 深蓝导航、白色内容、浅灰蓝背景；医患分别浅蓝／浅青，角色文字同时保留 |
| 字号 | 临床字段标题20px加粗；正文17px；转写16px；辅助文字14px |
| 间距 | 8／12／16／24px；圆角6—8px，不给短内容固定空高 |
| 转写 | 时间左上、角色右上、详情在正文下方右侧；文本输入不补造音频时间 |
| 中栏 | 病史→既往与过敏→查体检查→诊断处理→基本资料 |
| 定位 | 固定章节按钮只滚动中栏；基本资料一次展开；异常按正文顺序定位 |
| 样式来源 | 页面只加载doctor.css、doctor-ui-v2.css、doctor-workspace.css三份CSS；历史v3—v6文件保留但不加载 |

移除基础样式中58／72px正文高度上限，防止长现病史与下方操作重叠。完整基本资料仍保留九个字段；过敏和既往用药保留在临床正文，不收入人口学折叠区。
