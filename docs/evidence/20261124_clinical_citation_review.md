# 医生引用、问诊语音与知识检索复核

维护候选修补了一个会使医生复核到错误说话人的缺陷。实时预览、字段提取和旧病历的字段详情现在核对原话、说话人、临床句子和音段的对应关系。音段内可以有多句话。无法唯一定位时保留引文，证据充分时才展示身份和时码。修补提交 `0a4d8b19c626f2f9b28abe43cfb27c14c7b975f5`。
