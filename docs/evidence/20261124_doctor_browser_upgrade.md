# 医生工作台换版时怎样取得新版

对同一地址和既有 Edge 配置，从 `22c7770` 切到 `d8ef9f7` 后，用普通模拟医生重开同一份就诊并查资料。普通重进、开新标签、关闭浏览器再开和普通刷新四组仍执行旧脚本。检索均返回五个片段，医生看不到新加的来源目录。另一个隔离试验仅更新脚本地址，普通刷新见到两份来源，前三种普通重进仍取旧页面。

## 安装与使用

完成当前记录的保存后，从新部署的医生启动器重新打开。注册试用入口、状态页的工作台及知识链接、离线恢复包的打开命令都使用对应应用版本的页面地址。直接使用历史书签时，若页面仍是旧样式或缺少来源目录，保存工作后可在工作台按一次浏览器刷新。既有标签页会继续当前操作，系统不会在录入过程中强制切页。

工作台 HTML 在源站每次返回当前文件，并带有 `Cache-Control: no-store`。脚本和三份样式以归一化换行后的 SHA-256 前十六位区分内容。浏览器如果直接使用旧安装已缓存的书签页面，首次普通导航可能没有向新服务器发请求。[HTTP 缓存规范](https://www.rfc-editor.org/rfc/rfc9111.html#section-4.2.2)

## 工程复测

旧实现四项回归分别暴露了有条件请求仍返回旧缓存判定、资源地址与内容不对应、状态页入口缺版本及离线恢复入口缺版本。修补后，工作台缓存、注册启动器、离线恢复和既有工作台结构共 52 项本地检查通过。源码测试覆盖 GET、HEAD、脚本与样式标记、离线包和医生入口；既有课堂放映软件按其封存版本复核。本次工程变更不涉及临床模型、签署权限或病历字段。
