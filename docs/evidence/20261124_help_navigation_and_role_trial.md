# 医生帮助页返回与撤回身份的离线演练

## 帮助页与登录复核

普通医生从内嵌手册点击“返回上一页”，旧版本会留在手册页。Windows 上用 Chromium 与 Edge 分别做鼠标与键盘操作，四次均复现。首页也会错误启用“返回上一页”。浏览器实际事件显示从正文移到工作台按钮的焦点切换触发会话核查，关闭再打开弹窗会在按下与释放之间丢失点击。此前的远端运行 45390071345 通过了 Python 用例，界面审查在这一步失败。

工作台现在仅记录医生实际访问的帮助链接。会话复核期间，静态帮助仍可操作，病历区域继续遮蔽。如果会话失效，登录界面接管。修改后相同的四条路径返回帮助首页，首页返回按钮禁用。工程核对覆盖 79 项页面检查，另用真实服务撤销登录，延迟应答至点击完成，验证帮助返回、病历隐藏和 401 后回到登录的顺序。

复验命令为 `python -m pytest -q tests/test_doctor_session_check_playwright.py tests/test_partial_draft_help_playwright.py`，全套界面核查命令为 `python scripts/ui_review_check.py`。启动这两项时将仓库根目录加至 `PYTHONPATH`。

## Windows x64 合成演练 r2

交付目录的“软件／录音身份撤回试用”提供完整离线 ZIP、本机入口和核验记录。归档 73,193,401 字节，SHA-256 为 `0736595084598a54848e4767cafed50b73b21bb87673303aa1f282d651558d35`。包内 153 个应用文件匹配 `f4c12cfbaeeb220010ec7bac65e9a3004f7f79e3`。课堂 v6 和本节 r2 各自固定版本，这次帮助导航修改属于后续维护版。

模拟医生可回听右腕合成问诊第二段，撤回错误身份确认，重开并查看同一就诊的原稿。先前试用包曾在 Windows 关闭连接时持续等待。修订后的试用入口为演练服务设定有限的正常退出等待。独立复核从含空格中文路径解压，在 320 像素宽的 Edge 窗口按 Enter，从 5.89 秒实播至 6.260 秒。另一次 1366 像素测得实播至 6.278 秒。先后两次停止均关闭端口，重启后原声分段与 R1 保持一致。撤回后的新生成与新制签件均返回 409，正式审批数为零。以上均为本机测试和合成素材。

原就诊在身份订正后追加替代草稿仍需独立验证和集成。校方现场评分、目标医生评阅和医院放行继续等待相应责任人。
