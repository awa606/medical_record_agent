# 门急诊文书资料的候审、启用与回退

管理员导入同源材料的新版本后，普通医生继续查当前启用版的出处和正文。管理员可指定文档试查候审版，核对后启用，也可重新启用旧版。当前资料与所有历史版本各自计算词法排序。显示为“取自旧库共用登记”的出处只代表迁移时所见的值，恢复原始逐版出处仍需可信原件。

## 可用于演练的资料

项目整理了门急诊诊疗信息页试行规定的两份释义。首版三条，第二版补入信息页诊断的来源、描述性诊断用语以及该信息页保存期限的条文索引。两份 JSON 可通过管理导入接口在独立试库中核对。院内采用的版本和适用文书由病案部门确认。[三条释义](../../data/knowledge/review/outpatient-information-page/three-clauses.json) · [六条释义](../../data/knowledge/review/outpatient-information-page/six-clauses.json) · [原通知及全文](https://app.www.gov.cn/govdata/gov/202409/10/519291/article.html)

旧维护版对十二道固定问题的实测中，仅导入资料就改变了五道题的前五条结果或排序，也改写了旧版标题。启用六条释义后，三道新增条文题的正确条款均从未进前五变为首位，原有五道文书题仍全部进入前五。另有独立十八题的资料范围实验，八道有依据的题均能定位，六道问及个体用药或院内授权的问题也全部返回片段。资料命中与问题得到充分回答分别核对。

## 运行验证

- 两个角色独立登录，分别比较候审、修改候审、启用与恢复后的资料目录、精确来源、片段 ID、名次和返回分数。管理者历史试查及普通医生的数据范围分别验证。
- 源库迁移按当时观察到的共享来源登记。新版本单独登记来源。同一来源、版本和正文可再次导入。不同来源或版本若使用完全相同的字节，当前存储约束返回冲突，避免把旧文档误作新资料的入库回执。
- 用真实旧程序对已迁移副本尝试导入、启用、停用，以及修改来源或文档说明。旧写入被拒，旧程序可能返回通用错误。需要恢复旧应用服务时，从迁移前一致备份在单独实例恢复并核对；旧程序仍使用其原来的阅读和排序逻辑。
- 在 390 像素宽度的真实浏览器中，旧版“编辑”按钮在视口左边界 625 像素以外。新版按资料逐条排版，宽度 364 像素，能在同一屏读到当前版本并用键盘进入编辑，退出后焦点回到原按钮。桌面保持资料表格布局。
