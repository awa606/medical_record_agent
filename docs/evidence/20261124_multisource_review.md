# 医生修订的原话核对与课堂离线复验

2026 年 11 月 24 日，从维护分支基线 `cb0bb02` 复现两处问题。普通医生无法为现病史同时选择症状和用药原话，服务端也曾接受彼此矛盾的来源位置。在独立合成录音病例中，无原始时码的用药句被附上另一段的 1.2–4.4 秒，旧版实际生成了已签 PDF。

## 修改与依据

七个已有来源校验的核心字段在医生编辑状态下可主动选择多条原话。旧修订的引文保留作对照。本次勾选起始为空，可用 Tab 与空格选择、撤销。390 像素窄屏的操作按钮组可换行，页面宽度从基线溢出的 481 像素回到 390。控件取舍使用真实 Edge 键盘操作核对，复选框的分组沿用原生字段集和图例。[W3C 表单分组](https://www.w3.org/WAI/tutorials/forms/grouping/)

保存继续使用现有的整份修订事务。医生明确根据原文修正时，后端将提交的句序、文字、真实音段 ID 及时间与同一次就诊的来源核对。旧式 `start/end` 音段、无 ID、无时码、重复话、不同说话人分别处理。纯文本保持文字来源。普通手工录入保留人工来源，旧版签署与新稿确认分开。预览与经确认后保存的场景共享音段定位实现。[服务端来源定位](../../app/services/audio_citations.py) · [修订接口](../../app/api/tasks.py)
