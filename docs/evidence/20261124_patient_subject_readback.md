# 医生核实单句引文中的患者与陪诊者

模拟问诊中，患者说“陪我来的舅舅总说他头晕，我自己来是手腕痛了三天”。本地 Qwen3:4b 在一个已封存的两话轮病例里，把“头晕”写进主诉，“手腕痛了三天”写进现病史。模型主诉的引文在原文中确实存在，但指的是舅舅。该例的首次原答和医生后续订正分别保留。

## 医生怎样核实

从已保存的就诊打开病历字段的引文。在只有一句问诊、引文又短于整句时，点击“看完整原句”，即可读到说话人和同句中其余人的情况。文本和已定位的转写音段都沿用原有来源核对。未经确认的转写角色仍显示“角色待核”。原句重复某个词时，页面呈现整句，医生判断每一处的含义。字段为冲突状态时也可查原句。

| 复核场景 | 观察 |
| --- | --- |
| 旧版单句短引，两种屏宽 | 字段抽屉只呈现“头晕”。从工作台的问诊原文区可以读到完整句。 |
| 改进后 390 与 1366 像素 | 每种屏宽核对 17 张引文卡。短引、字段冲突、同句重复、已定位音段均可展开整句。双句保留“看前后原话”。 |
| 已经引用全文，以及来源缺失、索引、角色或音段不符等对照 | 这些卡片均未新增展开入口。两种屏宽的回读期间，观察到的写入请求为零。 |
| 键盘操作 | 在详情中打开和收起原句，按 Esc 回到原控件。新单句入口复用原生折叠控件及原工作台样式。 |

上述单句资料是隔离构造的历史文书，音频为带明确音段的测试夹具。两话轮病例走过维护版真实的普通医生生成路径，回放的是封存的首次回答。医生按原话更正主诉后产生新修订，批准并下载的 PDF 显示本人手腕痛，原 R1 保持原值。一次改作“手腕痛三天”时，被当作引文不能逐字支持的改写，仍需医生处理。该失败记录保留。

## 主诉生成的已知差距

另一位工程复核者事先封存了十份新合成问诊。对其中每份运行一次原维护版的实际本地模型，九份成稿，按预登记的来诊目的、主体与限定判据，忠实主诉为 2/10。在同一原答后增加归属检查，多拦住一例错误，忠实主诉仍为 2/10。原样重放验证了拒绝机制，未证实模型更会辨认患者。维护变更仅包括只读页面及回归测试。

研究阶段的旧版 4 项、候选 5 项各自在干净导出中完成。维护树上的历史引文、音段和入口缓存专项共 5 项通过。运行复核可使用以下命令。

```powershell
python -m pytest -q tests/test_transcript_source_presentation_playwright.py tests/test_doctor_release_cache.py
```

这些结果用于检查软件行为。来诊主诉在真实科室是否忠实、医生能否不经提示发现错误、查证修订耗时多少，仍需院方授权的数据与独立临床回卷。
