## 三人音轨上的实际转写

右腕与体检两份书面就诊各制作了三人合成录音。右腕 67 个参考字全部正确，体检 82 个参考字出现 4 个替换和 1 个插入。六轮原话中，取与合成分轨时间相交最多的系统角色，符合脚本身份的为 0/6。两份首次结果均要求人工核对，生成返回 409。新增的是 2 段录音；这两例已列入原有三份初诊。 两份录音各分配三种本机普通话声音，应用只收到混合 WAV。Windows 本机合成，使用维护代码 `69e2426`、断网 Debian 容器和冻结的本地 FunASR 模型，通过上传、首次转写、重读和尝试生成四个真实应用操作核对。两份转写均只产生两个声音组，自动接受数均为零。B 为 18.626 秒、3 个输出段；C 为 22.446 秒、4 个输出段。

独立复算将六个分轨与合轨逐帧回读，另查首次实际字面识别和身份建议。Edge 在 390 和 1366 像素宽度从独立解压目录打开、用键盘跳至六句播放，另页打开 WAV 原件并核对其摘要。阅读包 SHA-256 为 `cf9a060ca318f5b86b7fb87c46a29696720c3a1475edb3d74d69f286125507d1`。容器探针原始输出中的 source_commit 沿用了旧常量 `d8220b5`，本轮代码由实际挂载的 Git 归档校验，归档 SHA-256 为 `3e86e1ed76b8aefb48c241d89fcd415d4cd11f484c05b99f3f3a2541c7611fc6`。此处计分使用台词与机读时间轴，未测真人听感。

同一右腕录音另走跟随转写。普通模拟医生给三个输出音段依次写入患者、陪同人员、医生标签，三次保存后均从服务端读回。第二个音段（5.89–14.91 秒）混入父亲和医生两人的原话，整段设为陪同人员后，医生开头仍被归给家属。只处理一、两段时，生成各返回 409；给三段都打上核对标记后，软件总审核位为真，独立的角色质量检查仍待复核。 该次跟随转写另作记录，测试人员使用普通角色经真实 HTTP 接口保存。最终未请求继续生成，真实医生回卷仍为零。

在三人合成右腕问诊中，父亲和医生被归入同一声音组，部分原话还混在一个音段。普通模拟医生先按段改角色，再保存页面预填的整组身份，软件仍将组判为通过，生成接口返回 200 并创建了测试任务。这个工程失败保留为阻止医院发布的事项。固定课堂程序和两例合成纸面演练只用于教学。 对照中未经操作的空选择没有提交修改，仍返回 409。后续在隔离模拟模型下取得的 HTTP 200 证明生成任务被创建；本试验未产生临床认可。
