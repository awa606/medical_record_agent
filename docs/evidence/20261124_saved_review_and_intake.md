# 合成初诊首稿的医生修订与评阅收件

两例素材沿用同一批 B、C 合成口述及其本地 Qwen3:4b 首答，新增的是修订、签件与组织者收件证据。原批三例按既定四项要求仍为 0/3，复放没有发起新的模型推理。[三例首答与输入](20261124_synthetic_visit_timeline.md)

## 医生保存后可以读到什么

基线 `2f18a8f` 会在同一版结构化字段和 PDF 中保存医生补录的辅助检查，连续正文却漏记。修订版 `6cde0dc` 在新保存正文中保留已录入的个人史、婚育史、家族史、辅助检查和医生处理意见。部分完成内容保留提示，冲突内容只显示待核。未填写的可选栏目、系统给出的处理建议不进入正文。旧版本按当时保存的原文和分项分别查看。

| 软件实测 | 结果 |
| --- | --- |
| B，右腕就诊 | 普通模拟医生把本人影像待回记入辅助检查，把原因未定记在医生评估。从已登录工作台到下载一页已签 PDF 计 17 次控件操作。 |
| C，核对体检记录 | 普通模拟医生以本人原话修正主诉，在现病史保留姐姐转述和本人当前状态。实际查体接受缺失，辅助检查记录测量待核。到签件下载计 24 次操作。 |
| 旧签件跨版本读取 | 用旧服务写入并签发，再切到新服务，旧 R2 全文和原始分项各自保持，原签 PDF 按摘要重取一致。 |
| 已知栏目和安全反例 | 同一独立十项实测的旧版为 4/10，首候选 8/10，修正后 10/10。首候选对分行影像报告、来自体检中心的既往阴性报告均误拦，保留了首次失败材料。 |

上述控制次数只描述这两条工程路径。工作台可对主诉选择原文；辅助检查仍采用医生补录，临床报告签发人、报告版本和医院检查系统回执仍待接入。

## 已生成的首稿在模型服务停用后继续修订

在源版本 `af0beaf`，普通医生保存已生成的病历时，只运行本地渲染、证据校验和安全检查，原始模型抽取记录保留。以同一合成 B 的首稿逐分支核对，停用隔离的真实 Ollama 后，合法配置下旧版和新版都能编辑。将配置改为严格边缘模式搭配模拟提供方，旧版保存返回 503；新版既有首稿保存、应用内审核、PDF 导出均返回 200，相同配置的新生成请求仍返回 503。显式辅助检查冲突能作为待修改版本保存，审核返回 409，导出返回 400。未知当前模式拒绝普通修订，已记录的严格证据要求跨后续保存继续生效。[本地修订回归](../../tests/test_offline_saved_review.py)

## 三例合成评阅收件

组织者另存原题包，按本地发放登记的匿名代号逐组选择作答 JSON。工具核对冻结包、病例、阶段、可见来源和锁记。同组同例相同文件或相同内容只计一次，多个不同完整稿全部暂缓。跨组相同作答会提示核查独立性。回执只导出领包、时间、出处、指纹和状态，原始作答文字留在组织者手中。跨日补收可用原文件按组重新计算。[离线收件页](../../experiments/clinical-review-20261124/visit_timeline_intake.html)

独立检查在断网 Edge 的 390、1366 像素宽度分别登记 9 份测试文件。三份齐收后重复下载仍为 3/3，加入同组异稿后为 2/3；跨组相同记录共两条被提示，错误格式、错时出处两件退回。冻结分发包 SHA-256 为 `167679e8e34ae951f7c59f30f133f16352110619584263430c566006ea1830ef`。两阶段页已有 122 项冻结包检查，本轮补充组织者的收件端。真实病例、真实医生回卷、临床签核、学校正式打分均未在本轮取得。[离线收件回归](../../tests/test_visit_timeline_intake_playwright.py)
