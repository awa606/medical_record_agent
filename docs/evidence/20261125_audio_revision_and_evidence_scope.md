# 同次就诊订正录音、字段提示与资料用途

核验的软件提交为 `d231e1c5f0c120fa15b3cc228cbfec12c345ecfd`。普通经治医生可在进行中的未签音频就诊对照旧版与订正后转写，回听当前分段，选择要保留的文字或要引用的原话，追加新修订。当前版本及历史详情提供新旧依据摘要。医生修改前的版本保留其原始内容和来源，已签 PDF 可以按旧摘要取回。

| 核验内容 | 观察结果 |
| --- | --- |
| 同一就诊中的普通操作 | 先撤回身份确认，此时禁止新增签件。将分段明确订正并确认后，在同一任务追加 R3。主诉由医生保留，原既往史只留在历史版，辅助检查改引当前原话。新版本经逐项审核签署并下载 PDF。 |
| 并发与签件 | 过期录音或病历版本返回 409，前台保留选择。未提交的另一标签页保留输入。重复提交同一组选择仍只得到一个新修订，注入写入故障时整笔回滚。旧软件签署的 R2 随原库升级后，原记录和批准不变，重新取回的 PDF 字节相同。 |
| 操作体验 | 普通浏览器在 1366、390、320 像素宽可打开同一次就诊。固定三人问诊的 390 像素实测从 5.89 秒开始播放第二段。该例原识别把父亲和医生混在一起，测试能证明版本处理，不能证明改认一个身份在临床上正确。 |
| 缺失栏 | 没有字段值时，模型未经证实的断言可在原始提示中查阅。字段卡与审核清单展示记录状态或医生所作决定。医生补录进入新修订，可追查旧值。合成 W-B 的错误左腕归属保留作失败证据。非空但范围过宽的字段值仍需独立核验。 |
| 知识资料 | 普通医生在来源卡看到所选资料版本登记的适用范围和出处。8 道有依据的题都在前五条命中预期条款，6 道越界题也都有结果。另有 4 道预先独立编写的对照题。22 题的来源、段落和排序均可与原版对照。检索尚未判定片段是否充分回答个体治疗或授权问题。 |

在集成树执行音频修订 API、普通工作台、会话切换、字段展示和知识发布回归，得到 41 项通过。全套界面审查 79 项通过。字段与检索两项先行整合时的相邻回归为 88 项通过。每一批的条件不同。

复跑时在仓库根目录设置 `PYTHONPATH=.`，执行 `python -m pytest -q tests/test_audio_source_revision_api.py tests/test_audio_source_revision_workbench_playwright.py tests/test_doctor_session_check_playwright.py tests/test_missing_field_hint_presentation.py tests/test_knowledge_publication.py`，界面审查执行 `python scripts/ui_review_check.py`。

受控医院试用仍待授权的真实问诊和参照病历、目标医生独立评分以及医院的发布决策。学校现场展示和教师评分单独登记。
