# 辅助检查与查体分栏的合成首稿评阅

本项目的医生工作台有辅助检查栏。为核实生成时能否保留检查对象、完成进度与出处，使用同一冻结的本地模型，在离线隔离环境中对照原版、在抽取契约和规范化中增加辅助检查栏的候选，以及进一步增加一段通用检查进度说明的候选。候选属于工程研究。r4.2 随身包沿用原有推理和签署流程。

原版与第一个候选先观察同一位合成肘部就诊的四个连续时点。第二个候选随后在相同四点上复测，又在六个独立合成就诊上进行三组对照。新题和判据在开答前分别冻结，候选提示在收到新题前封存。每一组新题有 6 份普通医生 R1、6 份首次模型回答和相应传输记录，任务重试为 0。旧四点属于同一病例的回归；不可解释为四个独立患者。

## 六个新就诊的首次病历

✓ 表示当前辅助检查栏正确保留预定状态，相关引文能支持该事实。H1 对未谈检查允许字段留空。表中总数只统计这一栏。自述、查体的遗漏、错栏及冲突值另查。

| 合成病例及预定判断 | 原版 | 加独立字段 | 加字段与进度说明 |

| H2 左耳听不清。听力检查约在周五、尚未做 | 漏 | 漏 | ✓ |
| H3 心电图已完成、正式报告待回 | 漏，部分内容进入查体 | 只记报告待回，漏检查种类和已完成 | ✓ |
| H4 今日右膝超声明确未见关节腔积液 | 漏 | ✓ | ✓ |
| H5 母亲带来自己的胸片，患者本人尚未拍 | 漏 | 漏 | 漏 |

| **按预定判据合计** | **1/6** | **3/6** | **5/6** |

- H5 的最后一个候选在模型原始提示里提到患者尚未拍片，但没有形成有引文支持的辅助检查正文。病历该栏进入待核，未将母亲的阴影采纳为患者结果。
- H2 的“仅加字段”候选产生了三项无据否定，分别涉及发热、耳痛和耳流脓。这些值保存在带冲突标记的现病史及伴随症状候选中。面向医生的草稿正文为待核占位，系统未采纳这些否定。
- 最后一个候选在 H6 保留了右腕检查的当前状态和疼痛自述，但主诉待核，去年左腕旧伤转述进入“既往处理”。三组均漏了 H1 换鞋后好转和 H3 坐下后缓解。这些保护项不因辅助检查得分提高而抵消。

**发布判断**。六项辅助检查全部通过并保留关键自述及查体是本轮试前条件。第二个候选未达标，继续保留为隔离研究。六例是固定材料的工程判读，尚缺经授权的医院病例、独立临床评分与现场安全评估。
