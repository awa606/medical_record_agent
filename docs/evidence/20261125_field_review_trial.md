# 普通医生字段审核与离线知识检索

软件版本 `c06e48d1706385300cb40bcfe1c3265c538654bf`。本轮在普通模拟医生的审核页区分问诊原文、修订和知识资料，并从干净的 Windows x64 目录检查随包来源能否实际检索。全部问诊、病历、身份及签件使用合成材料。

## 字段操作

| 情形 | 界面与复核结果 |
|---|---|
| 本版有引文 | “查看问诊原文”打开原句。字段标有冲突且有引文时，入口显示“核对冲突引文”。 |
| 没有引文 | “查看字段记录”保留修订和审核信息，详情提示此字段没有保存原文引用。 |
| 修改字段 | 当前编辑值有变、复原原值、选择或取消本次引文时，入口名称随状态更新。医生修改后保存的历史引文使用“查看上版引文”作只读对照。 |
| 查阅文书 | “查知识资料”单击进入，与原文入口有不同的视觉层级。编辑中的文字可以参与检索，已存病历不因此改变。关闭后保留输入。 |

在 390、1366 像素宽度下从原版和新版的真实工作台分别操作。关闭后回到触发按钮。所测任务的 Tab 次数与原版相同。目标医生操作时间、误点率、临床采纳情况均待实测。

## 从源码到便携包的差异

第一次在空目录启动完整包，主诉、冲突引文和空记录能打开，知识查询返回 HTTP 503。服务在空索引上回读演示清单，包中缺少该清单。失败包 SHA-256 为 `f1aec78f1f5703a2f2eafa5501c1581096c21ee26289cd1c0870b70a77e6bfd5`。

修正包从固定的项目释义导入一份文书，存入同一演练实例的管理索引。通过授权管理员接口导入和启用，普通模拟医生仅能检索。已有的文书管理状态保留。启动中断后会校验写入记录再恢复。释义范围为门急诊信息页的六条索引，适用性由病案部门确认。[冻结释义](../../data/knowledge/review/outpatient-information-page/six-clauses.json) · [发布机关的正式文件](https://app.www.gov.cn/govdata/gov/202409/10/519291/article.html)

| 核验内容 | 结果 |
|---|---|
| 初始状态、停用、停服重开、显式启用、再次重开 | 固定查询“过敏”的目标片段数依次为 2 / 0 / 0 / 2 / 2，来源详情依次返回 200 / 404 / 404 / 200 / 200；五次病历及历史摘要一致。 |
| 归档内正常工作流 | 合成右腕就诊从 R1 修改至 R2，撤回错标、订正并建立 R3。普通模拟医生签署后下载 PDF，再开软件重新取得相同的 41,244 字节。 |
| 材料与推理 | 复用冻结的三人合成台词、校订转写和一次历史业务首答。成品使用期间实际调用新模型 0 次。 |
| 可分发性 | 在本机独立重构两次，ZIP 和构建清单逐字节相同。断网 Edge 在 320、390、1366 三宽从项目入口实际下载，均与原件一致。 |

修正包共 73,202,282 字节，SHA-256 为 `e79e69376a66a127e94457fd3d71c2feac722273916d723160a0793ec8c9d0fd`。原文、修订与检索的 65 项定向回归、相邻的 14 项页面回归和 79 项自动界面检查分别通过。路由层另用临时库复验了 12 种首次初始化、中断、停用和已有资料状态。本轮未组织具资质医生评审、学校评分或医院生产验收。

## 重建与回归

在完整 Git 仓库根目录执行。第一条命令需要对应的 r3 基础 ZIP，本机示例路径可替换。构建器验证固定 SHA-256 后才读取基础包，输出到新目录；所需应用与文书版本来自 Git 对象。首次接触压缩包的使用者完整解压后打开最外层中文说明页，由该页进入本机演练。

```powershell
python experiments/course-defense-20261118/field-review-trial/build.py --base "MediListen_同就诊来源修订_Windows-x64_d231e1c_r3.zip" --output "field-review-r4" --commit c06e48d1706385300cb40bcfe1c3265c538654bf
python -m pytest -q tests/test_portable_field_review_reference.py
```
