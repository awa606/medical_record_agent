# 同一名合成人从初诊到复诊

材料包括一名合成人、两次门诊、两份问诊对话及逐字段草稿，可用于核对一个实际操作问题：复诊时，哪些内容来自上次病历，哪些是本次重新问到或检查到的？时间、科别为项目编制，两个就诊均无真实患者或医师签署。[两次对话与病历草稿](../../data/knowledge/review/initial-followup-writing/synthetic-visits.json)

书写材料采用项目释义。原卫生部《病历书写基本规范》第十三条分别规定初诊、复诊的书写内容和急诊记录的时间精度，第十四条规定由接诊医师在患者就诊时及时完成记录。导入件区分了官网公开日期与规范施行日期。本例用虚构挂号时间区分两次门诊，实际接诊时是否及时书写仍需现场证据。[原规范](https://www.nhc.gov.cn/wjw/gfxwj/201002/79d42b9c8b3f47ee91000d31de116784.shtml)

## 导入与试用

在隔离演练系统中使用管理员账户进入「管理后台 → 知识库管理 → 导入资料」。以结构化导入件中的来源标识、标题、发布机构、来源链接、版本、用途、资料类型和适用范围填写表单，选择 UTF-8 Markdown 文件。界面导入后默认停用，管理员可先按指定版本验证，再在演练库启用、检查、停用。应用试用包 r4.3 原有的六条内置释义与本套补充材料分别核验。[表单用 Markdown](../../data/knowledge/review/initial-followup-writing/initial-followup-writing-v1.md) · [来源登记及结构化导入件](../../data/knowledge/review/initial-followup-writing/import.json)

## 已取得的证据

- 对两次就诊的 20 个草稿字段逐项复核，17 处引用均可定位。右肩当前变化、两年前的左肩病史、上次观察到但本次未重复的动作，以及已经检查但尚无报告的状态均有对应来源。诊断与签名留空。两份材料没有给出具体过敏药物。
- 正常管理员表单接收同一 Markdown，首次导入返回 HTTP 201，默认医生检索范围无结果。管理员指定待启用版本可查到急诊就诊时间须精确到分钟。390 像素宽度下可以启用及停用，医生默认范围的结果随之出现及撤回。
- 独立受控回放中，普通医生导入被拒绝。预先固定的四道文书问题有 4/4 在前两条检索结果中获得直接依据，首位命中 1/4。三道个体事实问题分别返回 3、4、3 个文书片段，可证明具体患者结论的题数为 0/3。
- 以上为一次性数据库和合成材料的工程复核。没有新增真实病历、临床人员读屏操作、临床首稿测评或院内知识条款审定。
