启动与检查

  1. 双击桌面“MediListen 医生试用入口”，点击“启动服务”，再“打开工作台”。正确地址是8795医生工作台，不要打开旧2626。
  2. 启动器显示网页可用时可登录查看历史；只有显示模型就绪才演示真实生成。预热期间不重复点击生成。
  3. 双击桌面“MediListen 数据与知识浏览器”，由入口完成本地认证。此处是带采样时间的只读快照，不能编辑病历，不是实时数据库。

连续操作顺序

时间操作应该看到什么
0–2分钟工作台找到“张示例／演示”，选择就诊E-13的“继续处理”。同一就诊的病历、版本与审核结果重开。先说明这是历史合成结果，经过人工修订。
2–4分钟在病历字段点击“查看原文证据”，再“查依据”。患者原文与指南分开；指南显示标题、版本、章节、页码和来源。检索命中不等于诊断成立。
4–6分钟“编辑整页病历”→按模拟原文作一处实际修订→保存。新Revision，旧批准失效；未重新审核时导出不可用。冲突需修正，不能仅勾选消除。
6–7分钟处理普通字段、缺失项、候选诊断及风险项→完成审核→导出→工作台重开。批准与导出绑定最新版本。未采集内容保留缺失，不填造；课堂模拟审核不代表医生临床复核。
7–9分钟管理员进入“管理后台”→资料目录→检索验证；查询“流感 临床表现”。7个版本、4个当前启用版本；可定位片段和原始指南。停用版本不进入医生默认检索。
9–10分钟只读浏览器沿患者→encounter→record_revision→approval/export_event；再看来源→文档→chunk→embedding元数据。可筛选、读长文本、沿关联打开记录；采样时间清楚。embedding数量不表示检索质量合格。

现场输入与失败切换

需要现场展示时，在工作台“登记并报到”→“开始接诊”→选择录音、上传或文本。使用无身份信息的短句，例如“患者今天发热，伴咳嗽和咽痛，没有胸痛，也没有药物过敏史”。角色不确定时先人工确认；模型引用或主体错误必须保留阻断。

若生成失败或出现内容冲突，说明实际失败层，停止反复重试；返回工作台打开已标明的E-13历史合成就诊继续展示持久化、原文、知识、修订与导出。历史备用不是对现场失败的掩盖。
