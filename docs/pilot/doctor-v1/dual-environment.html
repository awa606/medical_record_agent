MediListen · 2026-09-29 操作补充完整手册

展示版与使用测试版

先核对页头环境及版本。两版账号、病例和文件独立；同一时间只运行一版真实模型。使用测试版是功能测试候选，尚未放行独立临床使用。

入口用途数据
展示版 · 8795演示已有合成病例及历史流程保留展示历史、Revision、审核和导出
使用测试版 · 8798（占用时8799）自行新建匿名患者，上传音频、录音或输入文本独立新库；一条待输入合成示例，已启用知识资料

1. 启动与切换

  1. 双击对应的“MediListen 展示版”或“MediListen 使用测试版”桌面图标。
  2. 另一版未运行时点“启动服务”；需要切换时先保存或取消编辑、完成或取消录音，退出账号并关闭原页面。
  3. 点击“切换到本版”，确认已处理原页面内容。后台存在转写或生成任务时会拒绝切换；不要通过结束进程强行切换。
  4. 点“打开工作台”，使用本版的独立账号。页面可打开但模型仍预热时，真实生成保持阻断。

启动失败会保留数据；新环境启动失败时恢复原环境。端口被其他程序占用时不停止该程序。实际端口及版本以桌面“检查状态”为准。

2. 自行创建患者和上传

  1. 测试版工作台选择“新建匿名患者（自动生成编号）”，点击“登记并报到”。不输入姓名、身份证等真实身份信息。
  2. 核对“测试患者”编号，在就诊行点“开始接诊”。同一患者再次就诊时，选择已有测试患者后重新登记；患者编号保持不变，就诊号不同。
  3. 选择开始录音、上传音频或文本输入。支持 WAV、MP3、M4A、FLAC、OGG，最大200MiB；本版不支持视频。
  4. 等待真实转写；角色不确定时先人工确认医生／患者，再生成草稿。失败提示不会被替换成Mock结果。

报到失败后点“重试报到”，保留已经登记的就诊。不要重复创建。损坏音频请重新导出有效音频文件。

3. 原文与分项审核

  1. 文本输入病例左栏为“输入原文”；音频病例为“问诊转写”，恢复保存的片段、角色和时间信息。
  2. 病历顶部“医生分项审核”显示当前Revision和待处理数量。点“开始核对”，分别处理普通字段、缺失信息、候选诊断及冲突。
  3. 待核对不等于冲突；接受缺失表示医生知道尚未采集，不代表内容正常。证据冲突必须实际解决，不能仅勾选通过。
  4. 修改、保存后产生新Revision，旧批准失效。完成最新版本审核后才能导出。
  5. 重开历史就诊，已批准病例通过“查看审核记录”查看实际确认状态；不能从病历内容反推原文。

出现“原文加载失败”时重新打开该就诊；“未保存原始输入”表示该历史记录没有可恢复原文。保存失败时保留本地修改，不刷新页面。

4. 数据与知识展示

  1. 管理员从本版启动器打开“知识管理”，查看资料、启用状态、版本、来源和测试检索；医生通过病历字段的“查依据”检索。
  2. 点击“数据／知识浏览器”，工具从本环境生成一致性只读快照。核对来源环境、应用SHA及采样时间。
  3. 查看患者→就诊→Revision→审核→导出，以及来源→版本→片段→embedding元数据。快照不是实时库；再次打开此入口会显式刷新。

浏览器不能写库、执行任意SQL或下载整库。测试版新建匿名患者可进入本版快照；展示历史不会混入测试库。

5. 当前边界与反馈

字段漏提、引用或归属错误仍须医生核对。修复恢复和审核入口不代表模型质量通过；请记录版本、匿名就诊号、预期和实际结果。采用合成或授权去标识材料，不用于真实患者生产诊疗。
