医生试用 / 合成病例 / v1.1

医生工作台操作手册

候选版，以本机版本清单为准；尚未放行独立临床试用。

从工作台报到，到病历核对、审核与历史重开。

使用范围：中文发热／呼吸模拟问诊。AI只生成待核对草稿；本系统不是自动诊断或处方工具。手册截图对应本轮候选，示例患者均为合成。

快速开始

使用条件：已分配医生账号；只使用组织者提供的合成病例。

  1. 双击桌面“MediListen 医生试用入口”。启动服务，检查状态，再打开工作台并登录。
  2. 在工作台选择张示例、李示例或王示例，点击“登记并报到”；留在本页核对新就诊。
  3. 点击该行“开始接诊”。进入工作区后选开始录音、上传音频或文本输入。
  4. 停止、试听并提交录音；若角色待确认，先确认医生／患者，再继续生成。
  5. 对照原文逐项核对。修改后保存，处理缺失与冲突，审核最新版本。
  6. 导出病历并打开文件核对；回到工作台，重新打开同一次就诊检查保存结果。

成功后：工作台完成接诊准备；工作区完成撰写、核对与审核。

失败恢复：遇到阻断先看具体原因；不要刷新页面清除未保存修改。

01 启动与登录

使用条件：本机已由组织者部署；使用自己的医生账号。

  1. 双击桌面入口，点击“启动服务”。等待运行状态更新。
  2. 网页可打开不代表模型就绪。状态未就绪时可以查历史记录，但不能执行真实生成。
  3. 点击“打开工作台”，输入分配的账号和密码，再点击“进入工作台”。
  4. 核对顶栏账号。试用结束点击“退出”，再关闭窗口。关闭窗口不会删除已保存数据。

成功后：进入工作台，显示就诊任务与新建演示就诊入口。

失败恢复：启动失败时保留状态提示并联系组织者；不要改端口、重复安装或改用旧网址。

02 登记与报到

使用条件：已登录；三位示例患者均为合成病例，不是真实患者。

  1. 在“新建演示就诊”的下拉框选择张示例、李示例或王示例。
  2. 点击“登记并报到”。系统建立本次就诊，再完成报到；不会直接跳进工作区。
  3. 在列表核对模拟姓名、“演示”标识、患者标识和本次就诊 E-编号。
  4. 已有“已登记”记录无需再登记，直接点击该行“报到”。

成功后：记录显示“已报到”和“开始接诊”。同一模拟患者可有不同就诊编号。

失败恢复：若“登记已保存，报到未完成”，在原行点“报到”重试；不要重复登记。网络中断后先刷新列表核对。

03 开始接诊与选择方式

使用条件：记录已报到；开始前核对本次就诊编号。

  1. 在工作台点击对应记录的“开始接诊”。
  2. 进入就诊工作区后，先核对顶部患者、演示标识及就诊号。
  3. 现场模拟问诊选择“开始录音”；已有音频选择“上传音频”；已有文字选择“文本输入”。
  4. 已有病历时在工作台点“继续处理”或“查看病历”，恢复原任务，无需重新生成。

成功后：左栏用于转写，中栏核对病历，右栏查诊疗参考；五步条只说明进度。

失败恢复：未选就诊时会回工作台；报到在工作台完成。录音或编辑未处理完时禁止切换患者。

04 浏览器录音

使用条件：麦克风已连接；浏览器允许本机录音；双方仅模拟问诊。

  1. 点击“开始录音”，首次出现权限提示时允许访问麦克风。
  2. 看到录音计时后开始问诊；需要暂歇点击“暂停”，继续时点“恢复”。
  3. 结束点击“停止”，使用播放器试听声音和完整性。
  4. 确认后点击“上传并生成病历”。需要放弃时点击“取消”；取消后不要再次提交。

成功后：提交后出现转写和生成进度；角色不确定时进入角色确认。

失败恢复：无声先检查输入设备；拒绝授权后在浏览器站点权限中恢复。不把历史回放当作本次现场识别。

05 上传已有音频

使用条件：只使用获准的匿名 WAV／MP3 等页面支持格式；音频不包含身份信息。

  1. 在工作区点击“上传音频”。
  2. 选择组织者提供的文件，检查文件名与识别模式；按页面要求提交。
  3. 保持页面打开，等待转写。出现待确认说话人时先完成映射。
  4. 核对转写内容后继续查看病历草稿。上传不等同于重新现场录音。

成功后：可看到输入音频对应的转写与任务状态。

失败恢复：文件被拒绝时按页面显示的格式和大小要求更换；转写失败记录失败层，不连续重复上传同一文件。

06 文本输入

使用条件：已有匿名问诊文字；请明确医生／患者说话人。

  1. 点击“文本输入”。
  2. 删除默认练习文字，粘贴本次内容。可用“[医生]”“[患者]”区分角色。
  3. 检查是否含姓名、电话等身份信息，核对否定词、数值和单位。
  4. 点击“确认生成”，等待草稿。文本路径不执行ASR，不能用于证明录音识别质量。

成功后：中间病历出现待审核字段；模型输出仍须逐项对照原文。

失败恢复：生成失败保留原输入与错误信息，不通过改写事实来获得成功。

07 角色确认与原文核对

使用条件：已完成转写；角色不确定时系统阻止生成。

  1. 出现“确认说话人身份”时打开现有角色确认入口。
  2. 逐个试听或阅读对应说话人片段，确认谁是医生、谁是患者。
  3. 提交映射并检查待确认数量；门禁通过后再生成。无法确定时停止并反馈。
  4. 查看字段的“查看原文证据”，核对说话人、时间定位及引用是否支持该字段。

成功后：角色确认后允许继续；患者依据与指南资料分开显示。

失败恢复：医生提问不能作为患者事实，家属病史不能归给患者；不勾选猜测角色来绕过阻断。

08 核对与修改病历

使用条件：草稿已生成。AI首次结果可能漏提或引用不符。

  1. 依次核对主诉、现病史、既往史、过敏史、检查及候选方向。
  2. 特别检查“没有过敏”、家属事实、症状时间、温度与单位；缺失不表示正常。
  3. 点击“编辑整页病历”或字段“修改”，对照原文修订；原文及知识引用保持只读。
  4. 需要放弃本次编辑时点“取消编辑”；未保存内容不能通过切换患者自动丢弃。

成功后：字段进入编辑状态；主操作显示保存，审核与导出保持阻断。

失败恢复：“证据冲突”必须查明；修改动作是医生修订，不能统计成模型首次正确。

09 查看指南与参考

使用条件：需要核对医学依据，不向病历自动添加患者事实。

  1. 在字段旁点击“查依据”，或点击右栏诊断／治疗参考名称。
  2. 查看“患者依据”“指南资料”“待核对事项”三个标签。
  3. 核对标题、发布机构、版本、适用人群、章节和页码；展开来源详情核对片段与哈希。
  4. 检索命中只说明找到了参考资料。儿童指南仅适用于其声明人群，不能把相关资料视为已确认诊断。
  5. 完成后点“关闭”或按 Esc，返回原字段；未保存编辑仍保留。

成功后：来源、版本与正文可追踪；病例级参考明确区别于该条直接依据。

失败恢复：“未关联指南”“检索无结果”“服务不可用”含义不同。没有依据不能假定该诊断已被证实。

09A 管理知识资料（管理员）

使用条件：管理员账号；普通医生通过“查依据”使用当前启用资料，无需进行管理。

  1. 进入“管理后台”，默认先看到知识资料目录。按名称、状态或类型筛选；列表中的版本数不等于启用资料数。
  2. 点击资料名称，核对发布机构、版本、适用范围与使用边界。原始资料通过来源链接打开；ID、SHA和索引信息在折叠详情中。
  3. 点击该行“验证”选择一个版本；或进入“检索验证”，默认使用当前医生检索范围。输入问题后查看匹配原文、版本、章节和页码。
  4. 停用候选可被管理员指定检索，但不会因此进入医生结果。“索引状态”显示存储数量和最近查询的实际模式，不能据此推断临床质量。
  5. 导入时点击“导入资料”，填写来源及版本并选择UTF-8 TXT/Markdown文件（最大2 MiB）。导入后保持停用；完成验证后再显式启用。
  6. “编辑”只能修改来源元数据，标题和适用范围影响同来源所有版本；内容改变应导入新版本。停用不会删除历史内容。

检索范围：管理员输入问题不带就诊上下文；医生“查依据”还会加入该次就诊的病历信息，所以同样文字的排序可能不同。核对具体来源、版本、章节和原文，不要求排名相同。

成功后：管理员测试与医生范围区分明确，医生可核对当前启用资料的来源。

失败恢复：“服务不可用”需要重试连接；“没有符合筛选”需要调整筛选；“未命中资料”需要核查查询或索引。未通过页码定位的新版本保持停用，不以修改答案标签获得通过。

10 保存与版本冲突

使用条件：已核对修改；保持当前患者和就诊不变。

  1. 点击“保存修改”，等待成功提示；核对显示的实际Revision。
  2. 保存将产生新版本，旧批准失效；必须重新审核最新版本。
  3. 若提示版本冲突，保留本地编辑，先查看最新版本与差异，再处理本次修改。
  4. 若提示保存已提交但刷新失败，先加载最新版本核对，不反复点击保存。

成功后：保存成功后退出编辑，展示更新版本和待审核状态。

失败恢复：网络失败时不要刷新或关闭；旧版本不能覆盖新版本。将提示和就诊编号交组织者处理。

11 审核与受控导出

使用条件：修改已保存；当前显示的是最新版本。

  1. 进入审核区域，逐项确认已核对的字段；对缺失项选择保留缺失或先补充。
  2. 核对候选诊断与风险项；真实冲突不能仅靠勾选确认消除。
  3. 点击“完成病历审核”，确认状态变为已批准。
  4. 点击“导出已审核病历”，打开下载文件，核对内容、否定词、单位和就诊对应关系。

成功后：最新Revision批准后才可导出；导出文件沿用脱敏规则。

失败恢复：按钮不可用时查看角色、证据、缺失或版本阻断。不要让组织者直接改数据库解除限制。

12 历史重开与结束试用

使用条件：本次修改已经保存；未保存或录音未完成时先处理。

  1. 若导出详情仍打开，先点“关闭”；然后点击左侧“工作台”，按模拟姓名或患者标识搜索。
  2. 同名患者可能有多次就诊，请核对 E-编号与更新时间。
  3. 点击“继续处理”或“查看病历”，核对字段、Revision及审核状态。
  4. 结束后退出账号；组织者按需要停止服务，已保存记录不会因关闭窗口消失。

成功后：重开恢复同一次就诊和原任务，而不是生成新的病历。

失败恢复：历史未知记录仍显示脱敏患者标识；不要猜测或恢复真实身份。

13 故障、反馈与术语

使用条件：记录问题时只使用匿名试用编号、版本和合成就诊号。

  1. 启动失败：保留运行状态，联系组织者，不切换旧版本冒充恢复。
  2. 报到失败：刷新确认已有登记，在原行重试报到。切换被阻止：处理录音、未保存修改或冲突。
  3. 转写／字段不符：记录输入、AI首次结果、规则提示与人工修订，分别反馈。
  4. 从桌面入口打开“反馈”，填写任务、预期与实际、是否完成及是否求助，显式下载后交组织者。

成功后：反馈不自动上传。Revision是保存版本；候选诊断不是确诊；脱敏标识不是乱码。

失败恢复：不得在反馈中放密码、真实身份信息、原始患者音频。使用问题与临床判断问题分别记录。
