一页快速开始

  1. 打开：双击桌面「MediListen 医生试用入口」，点击「启动服务」。出现就绪后点击「打开工作台」，使用分配给你的医生账号登录。
  2. 选择就诊：工作台搜索合成患者，或填写演示登记信息建立本次就诊。不要录入真实姓名或患者资料。
  3. 采集：点击开始录音并允许麦克风；结束后停止、试听、提交。也可使用上传音频或文本输入。
  4. 核对：先确认医生／患者角色，再逐项查看病历；点击「查看原文证据」核对。点「修改」纠正或补充，保存后确认Revision更新。
  5. 审核与导出：处理未完成项，核对后逐项审核；最新版本批准后导出。重新打开历史就诊，确认保存结果。
  6. 反馈：从试用入口打开反馈表，写下卡住的步骤和预期结果，下载反馈文件交给组织者。

1. 打开与登录

网页以独立窗口打开，使用方式与桌面软件相近。模型预热时可以阅读历史内容，真实生成按钮保持不可用。启动失败时保留提示，联系试用组织者，不要自行修改端口。

每位医生使用独立账号，结束试用时退出登录。关闭网页不会删除已经保存的数据，也不会自动停止后台服务。

2. 登记、选择及恢复就诊

首次操作使用组织者指定的合成病例。页面可能将姓名显示为匿名编号，请按提供的SIM开头就诊编号选择。在工作台找到记录并进入就诊工作区；历史记录可以重新打开。现场登记只是本地演示功能，不代替医院挂号系统。

请核对患者标识与本次就诊，避免在另一条记录中修改。未保存修改不等于已经写入病历。

3. 录音或输入

开始录音后专心模拟问诊，支持暂停与恢复；结束后点停止，试听确认声音，再提交。取消表示放弃本次采集，不要再次点提交。麦克风拒绝授权时按页面提示处理；没有声音时请先检查输入设备。

可用匿名练习句：「今天发热三十八点二度，伴有咳嗽和咽痛，没有胸痛，也没有药物过敏史。」单人朗读只验证采音；完整角色流程需要医生和患者两方模拟。

转写和生成需要等待。历史结果回放、上传已有录音与现场录音是不同操作，不要混称为现场模型推理。

4. 先确认角色，再核对字段

出现「确认说话人身份」时，按录音确认医生与患者映射，提交后继续。不能为赶进度跳过阻断。

核对重点：主诉是否漏提，否定是否保留，家属病史是否误归患者，体温与单位是否准确。点击「查看原文证据」查看转写片段；点击字段修改或整页编辑后，保存并核对实际Revision。

「缺失」表示尚无足够信息；「证据冲突」表示需要检查内容与引用。不要仅勾选确认来消除真实冲突。

5. 查询指南依据

「查依据」用于查阅相关知识资料；右栏名称打开详情，区分患者依据、指南资料和待核对事项。核对指南标题、发布机构、版本、章节／页码和适用人群。

没有关联指南、检索无结果与知识服务故障含义不同，请按实际提示记录。指南内容仅供参考，不自动写入患者事实或生成处方。

6. 修改、保存、审核和导出

保存后确认成功提示和Revision编号。保存失败时保留编辑内容，不刷新或关闭；旧版本冲突时先查看最新版本，再决定如何保留自己的修改。

修改会使旧批准失效。逐项核对后批准最新Revision，再导出文件；打开导出文件检查字段及否定信息。最后回到工作台重新打开该就诊，确认内容仍存在。
