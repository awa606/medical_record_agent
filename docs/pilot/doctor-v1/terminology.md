# MediListen 使用界面术语

本表只规范显示文案，不改变数据库字段、查询参数、模型输出和历史证据。

| 中文主文案 | 保留原名 | 含义 |
|---|---|---|
| 数据与知识查看器（只读快照） | Datasette | 查看某一采样时刻的数据关联；不能编辑，不是实时库 |
| 患者／就诊记录 | patient / encounter | 一位匿名患者可关联多次就诊 |
| 病历版本／病历字段 | record_revision / revision_field | 每次保存的版本及其结构化字段 |
| 审核记录／导出记录 | approval / export_event | 与具体病历版本绑定的操作记录 |
| 资料来源／文档版本／知识片段 | knowledge_source / knowledge_document / knowledge_chunk | 来源、版本与可检索原文 |
| 语义向量索引 | embedding | 用于语义检索；索引数量不是质量成绩 |
| 病历生成服务／语音转写 | LLM Provider / ASR | 整理病历草稿／将音频转换为文字 |
| 内容校验值 | SHA256 | 核对内容是否改变，不代表医学正确 |
| 应用版本 | Git SHA | 定位实际代码版本；与模型摘要不同 |
| 应用筛选／下一页／排序 | Apply / Next page / Sort | 普通操作直接显示中文，查询参数保持原值 |

MediListen、FunASR、Qwen、模型版本、文件格式及编号保留原名，并在用途相关位置解释。未知技术状态保留原码并标注“未配置中文释义”，不猜测含义。患者原文、指南正文、账号、链接、路径、哈希及模型输出不参与全局替换。

锁形图标表示访问受限。查看器里的停用资料保留供历史核对，不表示医生检索会使用。修改病历回到医生工作台；维护资料回到知识管理。
