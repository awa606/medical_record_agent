现场组织者准备清单

教师到场前完成，交给教师后尽量减少提示

开始前

  1. 启动 Docker Desktop，使用既有8798启动入口恢复服务。不要启动8795或其他恢复副本。检查医生页能打开，在线生成服务已经就绪。
  2. 双击桌面“MediListen 教师现场试用”，再打开材料文件夹内“开始体验（医生工作台）”。在专用窗口中，用已有普通医生账号登录；不要用管理员账号替代。密码继续保存在原私密账号文件中，不写进教师材料。
  3. 将窗口最大化，回到工作台。关闭不相关文件和通知，确认扬声器与麦克风；本轮材料没有代替现场录音检查。
  4. 打开测试病例T01和操作指南。打印录音稿、反馈表，或让教师直接在材料网页填写并显式导出。准备纸笔记录本次就诊号。
  5. 检查网络。病历生成使用在线DeepSeek，断网时停止新生成；历史原文、已保存病历及本地材料仍可用于说明。

老师操作时

先让老师独立完成T01，建议预留15—20分钟，但不将建议时长记成实测时长。遇到障碍先记下按钮、提示、就诊号，再提供帮助。不要代替老师点完所有步骤，也不要为了演示成功反复生成。

录音是选做路径。使用本包合成朗读稿，不朗读真实患者资料；双人读台词时不读“医生／患者”标题。停止后先试听，声音异常先记录，不继续提交。

知识管理、数据查看器是讲解环节，由你演示。查看器8796是只读快照，采样时间与来源以页面为准；新病例不会自动出现在旧快照中。不要要求普通医生账号管理知识或修改数据。

结束后

  1. 请老师实际找到并打开导出的DOCX，返回工作台重开同一就诊，确认修改仍在。
  2. 记录AI首次输出、系统拦截和人工修订；反馈表未做项目填写“未测试”。下载后的反馈由老师主动交给你，不自动上传。
  3. 保存或取消编辑、结束录音，再退出医生账号。收集反馈时不包含账号密码、API密钥或真实患者材料。

历史版本体验

老师保存一次修改后，可在当前版本旁点击“历史版本”，选择旧版本对照原有内容，再关闭面板回到当前工作区。只读查看不会还原旧版或覆盖编辑；若无法打开，记录就诊号、版本及提示，保留当前修改并求助。
