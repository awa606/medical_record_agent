# 医生工作区 V2：三栏与大字号

状态：**NEEDS ADJUSTMENT**。V1被用户否决后，用户明确反馈：“字太小，而且我还是偏向于原有的三栏的前端”。用户看过V2后反馈“方向对，还需调整”，尚待具体细节。本版仅为匿名可点击样稿，未接入生产业务。

## 调整

- 桌面同时展示问诊转写、结构化病历、临床提示；品牌、导航、五步流程保留。
- 转写与病历正文为18px；主要按钮16px，章节标题18px，辅助信息不低于14px。不用降低字号解决空间不足。
- 右栏切换临床提示、原文证据和知识卡片，左右栏位置不变。
- 三栏独立纵向滚动，底部主要操作固定可见；录音按钮不随面板高度拉伸。
- 宽度不足1200px时保留转写和病历，辅助栏按需覆盖；不足800px时纵向排列。窄屏不强行压缩为三栏。

## 启动和检查

仓库根目录执行：

```powershell
python -m http.server 8767 --bind 127.0.0.1 --directory docs/prototypes/doctor-workspace-v2
npm ci --prefix tests/visual --ignore-scripts
npm test --prefix tests/visual
```

打开 `http://127.0.0.1:8767/`，右上角选择11种场景。模拟编辑、保存、审核、角色确认、取消均只改变页面内状态；不请求API、不访问麦克风、不读写业务文件。页面通过CSP禁止连接请求。

本轮68项布局与交互检查通过，覆盖1366×768、1440×900、1920×1080、1000×720。初次4项失败来自新增试听按钮与录音试听的可访问名称重复；已区别名称并完整重跑。原失败报告保留在本地 `.artifacts/alpha51-preview-v2/initial-results.json`。

这些检查**不等于视觉认可或真实三路径验收**。Edge已打开V2并读取页面状态，截图通道仍超时；未宣称Edge125%/150%或Chrome兼容已验收。当前截图由固定Playwright环境产生，仅存本地。
