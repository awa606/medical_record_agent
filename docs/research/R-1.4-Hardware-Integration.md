# R-1.4 Edge AI 终端硬件集成研究

## Problem

把 Jetson Orin Nano Super 8GB 开发套件、运行存储、供电、网络、USB 音频和安全安装结构闭合为一台可装配、可启动、可复验的 Alpha 工程原型。目标不是设计量产医疗硬件，也不把当前开发电脑的结果写成 Jetson 实机证据。

## Constraints

- 新增 Edge Terminal 必要采购成本不超过 3000 元；Existing Asset、Optional 与 Development Tool 分账。
- 现有电脑继续承担浏览器、麦克风采集和医生操作；Jetson 承担 FastAPI、ASR、LLM、SQLite 和文件存储。
- 8 GB 为 CPU/GPU 共享内存。开发机 6.5 GiB Spike 只能筛除明显不可行的方案。
- 保留原装 19 V 电源和主动散热，不在 Alpha 自制载板、电源或最终工业外壳。
- 所有 Required 项必须闭合功能、精确规格、接口、供电、机械、软件、包含关系、价格、来源、替代方案和验证方法。

## Existing Internal Solution

- [`EDGE_CANDIDATE.json`](../alpha_edge_candidate/EDGE_CANDIDATE.json) 已区分套件内部组件与独立采购项，但 NVMe、外壳、麦克风、网线和安装介质仍缺可核验报价。
- [`R-1.2-Alpha-Target-Environment`](R-1.2-Alpha-Target-Environment.md) 已证明常驻方案在 6.5 GiB 预算中 OOM；隔离 ASR 可运行，4B/1.7B LLM 在 CPU 筛选中均 300 秒超时。
- 当前项目已有开发机、路由器、显示器、键鼠、网线与六麦阵列线索，但尚无本轮实物型号、接口和可用性核验记录。
- `MRA-ALPHA-ENV-01 Rev.2` 仍是候选目标设备；没有采购、刷机或 Jetson 实机测试。

## Part Classification

### Required

1. Jetson Orin Nano Super 8GB Developer Kit。
2. 512 GB M.2 2280 NVMe SSD。
3. 安全绝缘安装基础：兼容壳体或开口支架、支柱、紧固件与防滑脚。
4. 可用 LAN 链路。
5. 可用 USB 音频输入链路。

### Existing Asset

现有电脑、路由器、显示器、键鼠、网线与六麦阵列。未完成型号和实物核验前，只能登记为候选复用资产，不能按零元自动关闭 Required 能力。

### Optional

完整美观外壳、摄像头、扬声器、电池、触摸屏和机械按键。删除这些部件，Alpha 的浏览器录音、本地推理、医生审核和受控导出仍能成立。

### Development Tool

16 GB 以上安装 U 盘、临时 DisplayPort 显示链路或串口调试工具。它们服务于安装和恢复，不自动成为终端运行组成。

## Digital Fit Spike

### Hypothesis H-HW-01

在不新增显示、电池、自制 PCB 和独立音频电路的前提下，使用完整开发套件包络、原装主动散热、底部 NVMe 与外接线缆，可定义一个不会遮挡接口和风道的 Alpha 最小安装包络。

### Input

- 官方完整套件包络 103 × 90.5 × 34.77 mm。
- 载板包络 100 × 79 mm、底部 M.2 Key-M 2280 位置、四周接口布局。
- 工程假设：左右/前后结构余量各 5 mm；顶部风道余量 20 mm；底部 NVMe 与绝缘余量 8 mm；线缆弯曲/插拔区不计入壳体本体。

### Procedure

1. 以完整套件而非裸载板作为占位体。
2. 单独建立底部 NVMe 服务区、顶部进风区和侧后方接口 keep-out。
3. 对 DC、RJ45、USB-A、DP 和 USB-C 标注插拔方向及外部维护区。
4. 检查候选结构是否能拆盖、换 SSD、清理风扇且不先拆除载板。

### Measured Result

- 计算得到的**概念内部净空下限**为 113 × 100.5 × 62.77 mm；这是设计余量推导值，不是候选外壳已验证尺寸。
- 完整套件、原装散热和底部 2280 NVMe 可以在概念包络中分层表示。
- 接口插拔、线缆弯曲、进排风与官方安装孔坐标仍需候选外壳 STEP/尺寸图或实物确认。
- 数字 Spike 证明“最小桌面盒结构可定义”，没有证明某一可购买外壳已经适配。

原始机器可读结果见 [`digital-fit-spike.json`](../hardware/alpha_edge_terminal/digital-fit-spike.json)。

## Unknowns

- **U01**：现有六麦阵列的型号、USB/UAC 行为、浏览器可用性和线缆。
- **U02**：至少两份完整 Required BOM 的含税运费报价。
- **U03**：候选外壳的精确内部尺寸、安装孔、底部 NVMe 和原装风扇净空。
- **U04**：JetPack 6.2.3 与 7.2.1 对本项目 ARM64/CUDA/PyTorch/FunASR/Ollama 组合的实机兼容性。
- **U05**：8 GB 共享内存、温度和降频下真实 ASR→LLM 串行闭环是否成立。

## Decision

`reuse_decision` 保持空值。

**Research Gate：NEEDS MORE EVIDENCE**

数字 Spike 已完成，但两份落地报价、六麦阵列实物信息、候选外壳精确尺寸和 Jetson 实机兼容证据仍会改变采购与外壳选择。不能填写 `REUSE`、`ADAPT` 或 `BUILD`。

## Fixed Seven Questions

1. **别人是否已经解决过？** NVIDIA 提供完整开发套件和机械/接口规范；Waveshare 与开源项目提供现成外壳路线。
2. **能否直接复用？** 尚未证实。套件可复用，外壳、NVMe、音频和软件栈仍需闭合。
3. **复用最大风险？** 名称兼容但安装孔、底部 SSD、原装风扇或接口开口不匹配，以及 8 GB 共享内存无法支撑真实模型链路。
4. **最小成本怎么验证？** 先做官方尺寸驱动的数字包络检查，再取得候选外壳图纸/实物和两份报价；设备可用后分层 Bring-up。
5. **证据是什么？** 官方机械规格、接口表、数字 Spike JSON、报价单、实物清单、温度/内存日志和可重复验证报告。
6. **为什么尚未选择 REUSE/ADAPT/BUILD？** 决策关键 Unknown 仍未关闭，提前选择会把兼容声明当成装配证据。
7. **判断错了如何回退？** 保留开放式绝缘支架为低风险回退，不采购可选部件；软件仍回到 `MRA-ALPHA-DEV-01` 开发基线。
