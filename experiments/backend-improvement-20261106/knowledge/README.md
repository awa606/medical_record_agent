# 知识检索：24 条冻结查询与人群过滤研究

2026-11-06 的独立工程实验。**结论为 `NEEDS MORE EVIDENCE`：人群过滤消除了本组已标记的人群误匹配，但没有提高片段命中率，也没有解决无答案问题。BGE 与旧向量的一致性检查失败后已经停止，没有混合召回提升或临床准确率结论。**

本目录只保存合成查询、公开资料的来源与校验值、工程测量及失败记录。不含业务数据库、患者原文、录音、账号、向量或模型权重。本次不修改生产知识库、原有 40 条查询和标签，不新增诊断或药物建议。

## 3. 实验方法与有效结果

使用项目现有分词、FTS5 BM25 查询代码，在内存 SQLite 中重建知识四表和两张检索索引。候选固定为 FTS 前 40 项，最终取 5 项；第二变体在人群过滤后取 5 项。整个儿童指南及 COVID 第 27—28 页的儿童专属章节标为 `child_only`，成人与年龄不明查询排除这些片段。

其他片段只标为 `all_ages_or_mixed`，意思是尚未标为专属人群，**不表示片段中每条建议都适用于所有人**。该粗粒度标注仍需细化。人口学条件来自冻结查询，不是临床信息自动提取成绩。

第一轮夹具错误地假设 `init_knowledge_schema()` 会回填 FTS，导致空索引、所有结果为零。检查后按 `ingest_pages()` 的实际逻辑填充分词表，在计分前验证 79 行索引及已索引词“流感”有结果。首次记录明确失效；有效运行只执行一次，没有挑最好结果。

| 指标 | 当前 FTS | 加人群过滤 |
| --- | ---: | ---: |
| 可回答问题片段 Hit@5 | 8/15，53.3% | 8/15，53.3% |
| 平均 nDCG@5 | 0.4679 | 0.4754 |
| Top5 不适用人群结果数 | 30 | 0 |
| 9 条无答案／需澄清问题返回非空 | 9/9 | 9/9 |
| 停用片段泄漏 | 0 | 0 |
| 返回片段正文 SHA 不一致 | 0 | 0 |
| FTS 查询 p50／p95 | 2.178／3.462 ms | 共用同次 FTS 查询耗时 |

延迟仅是本机 Python 3.13.5 的内存 FTS 查询，不含数据库服务、网络、向量编码、重排或页面加载；不是产品响应时间。第二变体复用同次 FTS 候选，不能把重复的延迟数字当成另一轮独立性能测量。

“非空返回”衡量本实验预期的保守查证行为：查询指定了本库没有的病种、版本、来源，或年龄尚不明确时，当前检索仍返回匹配词片段。它不表示系统已经给出了错误诊断，但不能把这些结果直接当作所问问题的有效依据。

## 4. BGE 运行缺口和停止原因

读取当前应用镜像发现没有 `sentence_transformers`，挂载缓存也没有完整的 `BAAI/bge-small-zh-v1.5`。项目保存了历史向量，却不能据此证明当前查询能编码或使用混合检索。现有检索在该依赖缺失时回退到 FTS。

按追加授权，在 D 盘独立研究目录补取同一官方模型，没有修改生产依赖：

| 项目 | 固定值 |
| --- | --- |
| 模型 | `BAAI/bge-small-zh-v1.5` |
| 官方 revision | `7999e1d3359715c523056ef9478215996d62a620` |
| 许可 | 官方模型卡声明 MIT；本目录只保存下载清单，不上传权重。 |
| 全部下载文件 | 96,405,966 字节 |
| safetensors 文件 | 95,827,648 字节 |
| 权重 SHA256 | `354763b9b1357bc9c44f62c6be2276321081ed2567773608c0d0785b61d5a026`，与官方 LFS 元数据一致 |
| 研究运行环境 | Windows，Python 3.13.5、Torch 2.10.0、Transformers 5.12.1；CPU、2 线程 |
| 编码方法 | CLS pooling、L2 归一化、最长 512 tokens、无查询指令；与现有生产 encoder 的配置意图一致。 |

先按片段长度排序选最短、中位和最长三片，预先固定阈值为余弦不低于 0.99999 且最大绝对误差不高于 0.0001。没有根据相似度挑选样本。

| 源片段 | 字符数 | 余弦 | 最大绝对误差 | 一致性 |
| --- | ---: | ---: | ---: | --- |
| 病历规范 p001-c001 | 9 | 约 1.0000001 | 1.81e-7 | 通过 |
| COVID p013-c013 | 526 | 0.9989879 | 0.007232 | 未通过 |
| 病历规范 p001-c004 | 1765 | 约 1.0000001 | 1.12e-7 | 通过 |

浮点计算出现略大于 1 的余弦属于数值误差，不是额外质量提升。两片一致不能抵消另一片失败。旧向量只记录模型名、维数和时间，没有权重 revision、tokenizer 与生成运行环境摘要；本次尚未查清差异来自何处。

**三片门禁失败后即停止：没有编码 24 条查询，没有真实独立向量召回或 RRF 质量成绩。** 仅用合成排名列表检查过 RRF 的合并机制，这不属于模型或检索质量测量。模型进程已经退出，旧 78 条向量未改变。

## 5. 判断与下一项最小验证

生产检索暂不升级。人群过滤研究只证明本组明确标注的儿童专属片段可以被排除，未达到“至少修复一项原遗漏”的晋级条件；无答案行为也没有改善。`Research Gate` 保持 `NEEDS MORE EVIDENCE`，不能称为辅助诊断通过。

下一步先查旧向量生成配方，定位不一致源片段的 tokenizer、截断、文本前处理与运行配置，不新增临床建议。若旧配方无法追溯，应明确新建隔离索引后重新冻结对照，不能直接把新编码器与旧向量拼接后声称同条件。

之后才讨论独立词法召回与语义召回合并、重排和无答案策略。RRF 只合并排名，不会自行判断病种、人群或指南版本；语义相似分数也不能直接解释为临床置信度。新增性能和质量实验应独立锁定输入、参数和停止条件，不在本轮结果上反复调参。
