# MediListen 课程演示候选

本目录保存两个可独立复核的前端改动。完整课堂包、已保存的模型首响应和本机试用数据由资料持有者在本地管理。

## 课堂投影回放

答辩交付目录已经包含构建好的工作台。双击“现场回放/双击启动课堂回放.cmd”，按启动窗口提示登录。初次启动建立本机数据库并创建普通医生账户。结束时在窗口按回车，下一次启动可继续同一病例。

要从仓库重建，将同一批次的 1.9.2-r2 课堂材料 `source/`、`fixtures/` 和 `frozen-sha256.json` 放在本目录的“冻结资产”下。安装仓库 Python 依赖及 requests，在本目录执行下列命令，目标“运行源”须为新目录。

```powershell
python build_replay_runtime.py 冻结资产 运行源
```

构建器验证 158 项原始资产，复用维护分支的医生端及版本绑定导出接口，应用课堂界面补丁，填入已核验的合成问诊并生成运行文件清单。Git 仅在重建时使用。启动后可在本机 26418 端口的 `/course/identity` 查到 `classroom-review-2` 和运行清单 SHA-256。问诊和外部模型首响应保存在资料持有者本地。课堂程序只回放这份响应，支持真实的版本修订、审核和 PDF 下载。

## 文档接诊工作台候选补丁

`reference-workbench.patch` 以 `experiments/frontend-reference-workbench-20261106/` 为基础，适用于独立的交互原型。该补丁保留中文输入法组合输入期间的键盘焦点，在响应式断点变化时更新布局，并改善队列投影显示。以下命令在临时副本中应用补丁，并用 Pillow 从原有品牌图生成 64 像素图标。新的 HTML 可直接双击打开。

```powershell
python experiments/course-defense-20261118/build_course_workbench.py 课堂接诊演练.html
```

## 课堂审核版 v2 复核

本版在同一套病例、版本和签署接口上改进首次使用流程。普通医生登录后返回启动器指定的本人就诊。风险卡同时展示原话、首稿和修改动作；文本出处保留段落信息。修改后，历史页优先展示有差异的字段。新导出请求绑定正在查看的修订与批准记录，重复下载复用已有签署文件。

使用合成病例和新建 SQLite 库，从正式启动器登录并完成 R1 → R2 → R3 → 分项审核 → 签署 → 下载一页 PDF → 刷新重开。Chromium 在 1366×768 和 1920×1080 均完整显示首要核对操作，390×844 的五步标签及四个顶层入口通过边界检查。另一次走查由登记开始，导入固定文本，生成的第一个病历版本与就诊匹配。真实患者和独立医生参与数均为零。

另外复核了导出中断重试、跨就诊切换、旧格式文件和跨页修订。冷备复测在原目录与迁移后的目录均下载到原签署 PDF，摘要一致，导出回执仍各为一条。迁移恢复的验证对象是带修订、批准及 SHA-256 的文件。四个会话用同一模拟账号读取一个病例的就诊、任务和就绪状态共 240 次，本机全部成功；这项小规模工程检查不支持医院并发容量结论。

本次运行清单 SHA-256 为 `1e51156c5a4cd597a8dddf1166e7186368900940963650759b25eeaad77a83b6`。从维护源码和冻结资产重建的 156 个运行文件及清单均逐字节一致。本机答辩包的“验证/审核工作台修补”提供真实界面、操作证据和可再次执行的浏览器脚本。实时音频和新模型生成按既有 Alpha 门禁另验。院方身份与病历系统联调、独立临床评估以及生产运维演练仍待医院合作。

## 早期投影版在 2026 年 11 月 18 日的验证

同一台 Windows 电脑上的 Anaconda Python 3.13.5 和独立 CPython 3.12.10 虚拟环境各自启动一份课程回放程序。两套程序目录、依赖目录、数据库和服务进程均独立。输入为同一例固定合成问诊，两侧健康与就绪检查均返回 200，24 个顶层结果键及完整字段树一致。每侧各回放一次，外部推理调用为零。

普通医生账号的浏览器角色走查覆盖登录、打开病历、查看原文、查询历史和进入编辑后返回。投影版在两种分辨率合计完成 20 次任务操作。另一次完整操作完成两处修订、版本保存、分项审核、实际 PDF 下载和刷新重开。首份草稿保留遗漏及字段混放，人工修订单独留存。该轮真实患者和独立医生参加人数均为零。软件结果限于课堂回放，正式 Alpha 项目仍按既有验收条件推进。
