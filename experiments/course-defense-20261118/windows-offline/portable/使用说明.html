MediListen 离线课堂使用说明

适用 Windows 11 x64。课堂使用一例固定合成问诊，演示医生核对、修订、签署和 PDF 导出。

  1. 在资源管理器中右击收到的 ZIP，选择“全部提取”。打开解压后的文件夹，保留“现场回放”和“专用环境”两个目录原有位置。
  2. 双击同目录的 双击启动课堂.cmd。首次启动会从随包文件准备 Python 与依赖。组织管理的电脑需允许执行本地 PowerShell 脚本。启动时保留控制台窗口。
  3. 在自动打开的浏览器中，用窗口显示的普通模拟医生账号和本机口令登录。进入固定就诊，核对原话、修订、签署、下载 PDF。演示完毕回控制台按回车。

本包默认地址为 http://127.0.0.1:26428，数据留在 %LOCALAPPDATA%\MediListen课堂专用\课堂数据-314。如需独立排练，在解压根目录的 PowerShell 中执行以下命令。请将目录名改为本次新排练的名称。

.\双击启动课堂.cmd -Port 26429 -DataRoot "$env:LOCALAPPDATA\MediListen排练-01"

若准备中断，可从同一文件夹重开。若提示端口占用，请回到原启动窗口按回车，或选择另一个空闲端口。程序帮助中的“历史课程展示顺序”属于旧环境，当前演示请使用本页地址。
