# Windows 专用课堂环境

在 Windows 11 x64 上，打开本目录的[双击启动专用课堂.cmd](双击启动专用课堂.cmd)。保持本目录与相邻的[现场回放](../现场回放/)原有位置。首次启动从随包文件准备解释器和依赖，然后打开浏览器。之后可直接双击启动。使用启动窗口显示的本机普通医生账号进入固定合成病例，演示结束后回到该窗口按回车。

默认地址为 `http://127.0.0.1:26428`，数据写在 `%LOCALAPPDATA%\MediListen课堂专用\课堂数据-314`。窗口只监听本机。如该端口已占用，可在原启动窗口结束已有演示，或按下文指定另一个课程端口。

## 首次离线准备

默认入口使用 PowerShell、同目录的 [CPython 3.14.10 x64 官方压缩包](python-3.14.10-amd64.zip)和 [28 个 Windows 轮包](wheels-win314-x64/)。离线拷贝时请一起保留版本锁、轮包核验清单、两个准备脚本和相邻的现场回放目录。首次准备不需要预装 Python 或管理员权限。组织管理的电脑需允许执行这一份本地 PowerShell 脚本。

在此目录打开 PowerShell，可以先单独准备环境。第一条命令只做准备，第二条命令启动课堂。

```powershell
.\windows_bootstrap.ps1 -Action prepare
.\双击启动专用课堂.cmd
```

本项目工作区内默认把解释器和虚拟环境放在 `.artifacts\20261124-release`。将本次交付复制到其他机器后，默认放在 `%LOCALAPPDATA%\MediListen课堂专用`。准备时逐个校验轮包内容，再用 pip 的本地模式执行带哈希的版本锁，最后核对已装包和 `pip check`。下载或安装中断后可重跑同一命令。只有本脚本创建且仍带匹配准备标记的环境会继续安装。已存在但内容不同的目录会提示另选新位置。

如需用两个全新目录独立复验，可在同一 PowerShell 窗口运行下列命令。已存在的课堂数据可继续保留。

```powershell
$folder = Join-Path $env:LOCALAPPDATA ('MediListen校验-' + (Get-Date -Format 'yyyyMMdd-HHmmss'))
.\双击启动专用课堂.cmd -HostRoot (Join-Path $folder 'CPython') -EnvPath (Join-Path $folder 'venv') -DataRoot (Join-Path $folder '模拟数据') -Port 26429
```

如需在可联网电脑上从 PyPI 重新获取相同轮包，可指定新的虚拟环境路径并加 `-Online`。该方式仍使用随包的官方解释器压缩包，按核验清单给出的精确文件地址下载，校验同一组 SHA-256，再执行相同的本地安装。将 `-NoBrowser` 传给启动入口可在受控测试时关闭浏览器自动弹出。

```powershell
.\windows_bootstrap.ps1 -Action prepare -Online -EnvPath (Join-Path $env:LOCALAPPDATA 'MediListen课堂专用\联网复建314')
```
