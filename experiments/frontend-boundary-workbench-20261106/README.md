# MediListen 三面板接诊工作台

面向医生接诊的隔离前端原型：连续病历在左，问诊原文与问诊辅助分别位于右上、右下。只使用两份固定合成病例，不连接生产 API、数据库、麦克风或临床模型。

## 打开试用

双击本目录 `启动接诊工作台.cmd`，或在本目录运行：

```powershell
python serve.py --port 23713 --open
```

- [新版交互原型](http://127.0.0.1:23713/)
- [同条件新旧截图与交互对照](http://127.0.0.1:23713/comparison.html)
- 旧 A/B/C 原型位于相邻 `frontend-layout-comparison-20261106`，本轮没有修改。

服务器仅绑定 `127.0.0.1`，只提供本目录静态文件。Python 3 与现代桌面浏览器即可运行，无 npm 安装步骤。`--help` 和 `--version` 已分别实际运行；当前启动器版本 0.3.0。

## 建议试用顺序

1. 选择合成患者甲，开始模拟录音，确认说话人。
2. 观察原文、临时病历及辅助摘要逐步出现，点击字段原文定位对应句。
3. 编辑临时稿；6/6 播完后结束采集，进入整理和核对。
4. 保存手改为新版本，逐项处理病程、缺失、候选和提醒，签署当前版。
5. 导出带合成标记的 TXT，完成接诊，返回列表并重开只读病历。
6. 在“演示控制”中检查失败、连接中断、保存冲突、空列表和长内容。

宽度小于900 CSS px时，原文与辅助进入命名面板。Escape 返回原入口与阅读位置。右下摘要只展示第一条追问和参考方向，完整追问、依据及长内容通过“展开／依据”查看。

真实100%／125%／150%浏览器缩放仍待完成，不能用模拟视口代替。未验证物理录音、真实 ASR、临床模型质量、真实断网、生产 PDF 或目标医生独立使用。用户审美认可另行记录。生产 Research Gate 保持 `NEEDS MORE EVIDENCE`。

草稿暂存在本标签页的 `sessionStorage`，仅为合成原型验证；这不是生产患者内容持久化方案。恢复必须明确选择，未保存手改不会自动覆盖正式版。关闭浏览器后的永久保稿不在本原型承诺内。
