# MediListen 接诊交互原型

这是“病历为主、原文按需固定、参考按需打开”的可运行设计样本。只使用两位合成患者和四个代表字段，用来验证任务流程及异常恢复；不是生产修复包。

## 启动与试用

Windows 双击 [启动交互原型.cmd](启动交互原型.cmd)。需要现有 Python 3，不安装第三方依赖。默认地址为 <http://127.0.0.1:23709/>；关闭命令窗口或按 Ctrl+C 停止。

也可在仓库根目录运行：

```powershell
python experiments/frontend-design-20261105/serve.py --open
```

若端口已占用，先查看现有预览，或使用 `--port 23710`。不要双击 HTML 文件，也不要用 Windows 默认 MIME 配置下的 `python -m http.server`：部分机器会把 `.mjs` 识别为纯文本，导致空白页。专用启动器已固定模块 MIME，并且仅提供这个原型目录。

推荐试用顺序：

1. 选择合成患者，打开“输入问诊文本”，点击“载入合成样例”。默认输入为空。
2. 整理草稿，固定原文并排，点击字段“原文”，修改并保存新版本。
3. 处理缺失、冲突、候选与提醒；选择只在签署后正式提交。
4. 签署、生成文件、下载，完成本次接诊并返回列表。
5. 在“演示场景”中体验空列表、连接中断、生成失败、保存冲突、下载失败；可重置两个病例的演示进度。

录音入口只模拟开始和停止；音频入口选择内置转写，不访问麦克风或上传文件。所有生成结果固定，输入编辑不参与模型推理。导出为带合成标记的 TXT，包含当前签署版本及核对决定，不模拟生产 PDF。

## 这版具体改变了什么

| 医生任务 | 原型表达 |
| --- | --- |
| 选患者 | 一套列表、搜索和筛选；继续入口明确患者 |
| 采集 | 三种入口都显示当前患者与就诊；不默认预填样例 |
| 核对 | 病历为稳定主区；四类异常靠近对应字段 |
| 对原话 | 宽屏可固定并排；900px以下进入辅助面板并返回原位置 |
| 保稿 | 按合成用户及就诊隔离；离开可暂存或放弃；恢复不覆盖已保存版本 |
| 签署 | 保存生成新版本；修改后旧签署不能用于新内容导出 |
| 导出 | 回执显示患者、就诊、版本、签署及生成时间、文件名和下载状态 |
| 完成接诊 | 明确返回列表，完成后只读查看及下载 |

深蓝、白底和连续章节沿用现有品牌。900px以下滚动时保留患者身份、章节导航及底部状态与动作。正文只实现主诉、现病史、过敏史、初步诊断四字段；生产其他章节没有删减或迁移。

## 数据和接口边界

原型不调用生产 API、不启动业务容器、不迁移数据库。演示状态仅保存在当前标签页的 `sessionStorage`，命名空间为 `medilisten-synthetic-prototype-v1`。该机制只用于合成 Spike，不能作为真实患者内容的生产持久化决定。请勿输入真实患者资料。

刷新读取暂存后，先展示已保存版本，要求明确恢复未提交内容。浏览器的标签恢复机制可能恢复会话；需要明确清除时使用“重置全部演示”，不要把关闭窗口当作安全擦除承诺。

生产候选接口继续受现有生成、保存、版本、签署和导出约束；完成接诊优先复用 `POST /api/encounters/{id}/complete`。接口接入、服务端版本冲突和患者数据持久化尚未实施。
