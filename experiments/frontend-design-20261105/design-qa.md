## 联调中发现并修复的原型问题

| 问题 | 修复及复测 |
| --- | --- |
| Windows默认MIME使模块不加载，页面空白 | 独立serve.py显式提供JS MIME；重载后正常 |
| 暂存离开后从列表选B又询问离开A | 仅活动接诊的未暂存内容触发离开保护；A/B隔离路径重走成功 |
| 旧历史“当前版本”读取dirty正文 | 改读已保存revision；实际打开历史核实 |
| 原文索引硬编码、角色混标、缺失项错误匹配 | 多轮固定对话、显式角色、缺失提示；点字段定位患者语句 |
| 导出使用错误下载状态字段和当前编辑内容 | 按导出快照读取状态/版本/内容，回执实测与下载读取 |
| 已存在导出再次打开无反应 | 复用当前签署版本的已有快照，完成后仍可打开 |
| toast长期遮正文及旧签署提示遗留 | 5秒消退，新状态清除旧通知；13图片及DOM确认toast为空 |
| 窄屏滚动患者身份离屏 | 复用患者条sticky；800宽实测patient范围0–56px、章节56–102.67px |

失败事实保留在本表及本轮工具记录，没有把首次未通过改写成一次成功。B下载事件等待曾导致工具超时，重新读取页面后通过可见按钮发起下载并核对本地文件；不将该超时解释为业务下载失败。
