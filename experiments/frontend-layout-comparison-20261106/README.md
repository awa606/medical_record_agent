# MediListen 三套布局交互比较

使用同一病例、同一状态模型比较三种工作区布局。此目录为隔离设计实验，只使用固定合成病例，不调用生产接口、麦克风或医疗模型。

## 打开原型

双击 `启动布局比较.cmd`，或在本目录执行：

```powershell
python serve.py --port 23712
```

浏览器打开 `http://127.0.0.1:23712/`。主页默认使用 B 持续对照。布局说明见 `comparison.html`，也可点击页面右上角“布局说明”。

| 方案 | 初始地址 | 工作区组织 |
| --- | --- | --- |
| A 文书优先 | `/?layout=document` | 病历居中，原文与诊疗参考按需打开 |
| B 持续对照 | `/?layout=compare` | 病历与完整原文并排；采集中也保留原文，问诊辅助可折叠 |
| C 问题引导 | `/?layout=guided` | 左侧待核对导航，右侧连续病历，处理动作仍在正文原位置 |

顶部 A/B/C 控件仅用于设计比较。它们共用当前页面的一份病例状态；切换不提交、不丢弃编辑稿或审核决定。小于 900 CSS px 时辅助内容进入面板。

## 试用顺序

1. 从今日接诊选择合成患者甲。
2. 开始模拟录音并确认说话人；可暂停、继续或逐句播放，观察临时病历和辅助提示。
3. 切换三种布局，打开字段原文、临时编辑，再结束采集进入核对。
4. 编辑保存，逐项核对，签署当前版本，生成并下载演示 TXT。
5. 完成接诊返回列表，选择患者乙检查内容归属。

“演示控制”保留无列表、连接中断、生成失败、保存冲突及下载失败等合成状态。模拟结果只证明交互，不能证明真实录音、模型、临床或生产接口质量。

## 数据与边界

- 复用相邻 `frontend-design-20261106` 的 `model.mjs` 和 `capture.mjs`，没有修改二者的业务状态契约。
- 暂存仅使用浏览器标签页的合成会话，键名为 `medilisten-layout-study-v1`；不与旧原型混用。
- 请勿输入真实患者资料。恢复稿不会直接覆盖保存版本，未提交内容离开前仍需处理。
- `serve.py` 仅监听 `127.0.0.1`，不发布公网。
- 生产 Research Gate 仍为 `NEEDS MORE EVIDENCE`。此原型不代表生产前端已改版或用户审美验收通过。

## 验证

```powershell
node --check app.mjs
node --test model.test.mjs capture.test.mjs
```

2026-11-06：语法检查通过，44 项复用状态测试通过。实际 Edge 操作覆盖采集、原文定位、布局切换保稿、保存 R2、刷新恢复、四项审核、签署、导出回执和完成接诊后切换患者。窄屏原文面板曾只显示遮罩，局部修复后重验通过。**实际下载事件超时，文件下载与内容仍未验**；这不是全流程验收通过。

CSS 1440×900、1366×768 和 800×600 已检查，实际浏览器 125%／150% 缩放、真实音频与模型、用户审美和目标医生独立试用尚未完成。详见 [浏览器验证与设计 QA](design-qa.md)。
