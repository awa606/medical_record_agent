# MediListen 文档接诊工作台

以成熟产品的工作区、文档和辅助面板模式重做的可交互原型。使用两份固定合成病例，流程保持：选患者→采集→核对病历与原文→保存→处理审核→签署→导出→完成接诊。

## 打开

双击 `直接打开工作台.html` 或 `启动接诊工作台.cmd`，无需安装依赖或启动服务器。此双击入口仍待浏览器实际验收。

需要HTTP服务时，双击 `启动本地服务器.cmd`，或执行 `python serve.py --port 23714 --open`。

- [工作台](http://127.0.0.1:23714/)
- [设计来源与实际映射](http://127.0.0.1:23714/references.html)
- [同条件对照](http://127.0.0.1:23714/comparison.html)

静态服务仅监听127.0.0.1。无安装前端依赖步骤。旧三面板位于相邻 `frontend-boundary-workbench-20261106`，不修改。

## 试用

选择合成患者甲，开始模拟录音，确认角色，播放六句。可查看原文、编辑临时稿，然后结束采集。保存编辑稿，逐项处理四项审核，签署本版，导出带合成标记的TXT，完成接诊。历史、失败、断连、恢复、保存冲突和空列表可从现有入口试用。

顶部“设计参考”说明参考网站具体映射到哪些区域。病历连续阅读，原文角色与句子同排，辅助先显示下一项和剩余数量。小于900 CSS px时原文与辅助进入独立面板。

## 边界

这是隔离原型，模拟录音不会开启麦克风；不连接生产API、数据库或临床模型。sessionStorage只用于本标签页的合成状态，不是生产患者保稿方案。下载格式为TXT，生产PDF不在本轮验证内。

原生浏览器缩放与模拟视口分别记录。最终GUI、视觉与部署结果以 `design-qa.md` 为准。代码存在和模型测试通过不等于用户审美或医生验收通过。
