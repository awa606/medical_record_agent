参加两轮合成复诊资料试用

请直接从本页开始。两轮各有一位虚构患者，你可以自行阅读、返回和记录答案。任务页会给出相同的问题，请在两轮结束后再看设计对照说明。

  1. 在 Windows 文件资源管理器打开本页所在文件夹，双击 双击开始合成试用.cmd。保留启动窗口，等待浏览器打开任务页。如果浏览器没有自动打开，复制窗口中的本机网址到浏览器。
  2. 依次完成两轮。计时、答题和保存记录均在任务页。每轮资料在一个新标签打开，可随时回任务页。请选择同一输入设备和浏览器宽度。
  3. 点击“保存本机观察记录”，在浏览器下载目录确认 JSON 后，点击“结束并关闭本次服务”。需要中途退出时也可结束服务或在启动窗口按 Ctrl+C。

若领取的是轻量试用 ZIP，先完整解压。启动脚本、任务页、合成素材和参与者说明需要放在同一文件夹。

另一个 Windows 电脑如何开始

把本试用文件夹完整复制到 Windows x64 电脑，再把官方 MediListen_字段审核_Windows-x64_a2f6c31_r4.5.zip 原样放到启动文件旁，双击开始。完整交付目录已能自动找到该包。首次会利用包内的 Python 和锁定轮包在该 Windows 用户目录建立离线环境。每次重新启动会生成新的临时合成库。

记录、隐私与退出

仅填写合成问诊内容。表单保留在当前任务标签，观察 JSON 由本人下载。关闭服务后临时合成记录随正常退出清理。正式产品包保持原样。已关闭的任务需要重新启动并作答；个人作答不会自动发送。
